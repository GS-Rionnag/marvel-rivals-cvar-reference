# Ray tracing CVar notes: batch B

This page records the 25 exact names assigned to this batch. Meanings and stated defaults come from captured community help in [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322). The values shown are from the captured [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452) snapshot; they are not presumed defaults or recommendations. The source build and capture procedure are not established. Types are the registry's captured types.

## Evidence limits and using overrides

The local evidence is a static address scan of Marvel Rivals Shipping build `1.1.4042190`; scan details and limitations are in [`the source notes`](EVIDENCE.md#build-specific-static-analysis). An address-taking reference is address/setup evidence, not proof of a value read. Direct-memory candidates show code accessing storage associated with a registry `ref_rva`, but do not prove the path executes in a live match or establish the full runtime effect. The scan found non-address-taking direct-memory candidates for nine names: `DynamicGeometry.SharedVertexBufferGarbageCollectLatency`, `DynamicGeometry.SharedVertexBufferSizeInMB`, `EnableInGame`, `EnableMaterials`, `EnableOnDemand`, `ExcludeDecals`, `ExcludeSky`, `ExcludeTranslucent`, and `Geometry.GeometryCollection`. `DebugVisualizationMode.ProceduralPrimitives` has a registry `ref_rva` address-taking match but no direct-memory candidate. The remaining 15 names also have no direct-memory candidate. Absence from this scan is not proof a CVar is unused.

An entry can be written as `name=value` below `[Overrides]` in the mod loader INI format documented in [CVar overrides](cvar-overrides.md). This describes syntax only: registry presence, help, snapshot values, and static references do not establish that the loader accepts a line, that the game registers or honors it at runtime, or what it does in a live session. No runtime override was tested for this batch. No exact UE 5.9 match is used here to expand the captured help; upstream engine matches, where present in the general catalog, are context and do not prove Marvel Rivals uses the same implementation.

## Reading the findings

The registry help is the source of the descriptions and any stated defaults. The snapshot records a captured configuration, not what the game necessarily uses by default. Direct-memory instructions raise confidence that some code consults the CVar storage, but this static scan did not trace those instructions through control flow or observe the effects in a match. Several settings concern ray-tracing renderer paths; their registration in this community capture does not show that the relevant path is active or configurable in the shipped game.

For raw evidence and method details, see [`the source attachment notes`](EVIDENCE.md#build-specific-static-analysis), [`the complete community registry`](cvar-community-registry.md), and [`the local build address scan`](EVIDENCE.md#evidence-artifacts-not-included).
