# Chaos game-specific controls, batch A

This page covers 25 `p.Chaos.*` entries in the preserved community `var`/`ref` table that are not part of the focused solver, collision, scene-query, or geometry-collection guides. It groups game-side destruction/client controls with diagnostics and a few Chaos engine controls. Exact names, types, community descriptions, and snapshot values come from the attached registry and `CVarDump.txt`; the attachment does not identify its game build or collection method. Captured values below are not assumed defaults.

The local evidence is the saved RIP-relative reference scan against Marvel Rivals Shipping build `1.1.4042190`. A direct memory candidate shows that code references the CVar's `ref_rva`, but an address scan alone does not prove the surrounding full behavior, normal-match execution, or that a startup override reaches the read. Instructions listed below are the saved candidate sites; no in-game tests were run. None of these names has a separate entry in the saved Chinese-help translation list.

## Evidence and limits

- Exact names, types, help, and reference RVAs: [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322). Captured values: [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452). The snapshot is not a verified default set.
- The saved address scan is [`build-4042190-cvar-address-hits.tsv`](EVIDENCE.md#evidence-artifacts-not-included). The listed instruction addresses identify code references to values; a compare/load is stronger than an object-pointer hit, but neither alone reconstructs full control flow or proves a particular branch executes in a match.
- The names do not appear in the Chinese-help translation guide. No translated text was needed for this batch; malformed or very short English help is retained as-is and called out where it conflicts with the CVar name.
- Loader syntax can express `name=value` lines under `[Overrides]`, but this static research does not prove startup acceptance, final applied values, or visible effects. No runtime override was tested. See [CVar override evidence levels](cvar-overrides.md#does-a-cvar-actually-change-in-marvel-rivals).
