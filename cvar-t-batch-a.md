# Lowercase `t.*` CVar batch A

This guide documents the 23 currently uncovered lower-case `t.*` `var`/`ref` entries. They cover FPS charts, hitch and frame-time thresholds, frame-rate caps, background idling, latent-action timing, and Streamline Reflex controls. Each row keeps the community snapshot separate from Epic UE 5.9 context; neither is proof of the installed game's effective default.

Static scan counts below match the community registry's `ref_rva` and `obj_rva` fields against build 1.1.4042190. Direct-memory candidates do not establish whether code reads, writes, or merely compares an address. No runtime or loader override tests were performed, so `.ini` editability and live effect remain unknown.

## Interpretation limits

- The Epic defaults and descriptions are upstream UE 5.9 context, not proof that Marvel Rivals uses the same implementation or value. Several settings have community snapshots that differ from Epic defaults.
- The FPS-chart and hitch thresholds describe metrics and visualization behavior; they do not directly promise a performance increase.
- Streamline Reflex help describes extension and latency-mode switches, but does not verify the game's NVIDIA integration, driver requirements, accepted override timing, or resulting latency.
- `t.UnsteadyFPS` is described as deliberately randomizing FPS; that is help text, not evidence that the local Shipping build currently executes it.
- Static scanner matches do not establish reads/writes or execution. No controlled runtime test changed these CVars.
- The registry does not prove that the mod loader accepts these names in `.ini` overrides.
