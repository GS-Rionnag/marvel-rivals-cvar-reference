# Audio CVar batch A

This guide records the first 25 alphabetically sorted currently uncovered registered `au.*` variables from the supplied community registry. A CVar’s help text describes intended behavior, not proof that Marvel Rivals consumes an overridden value. Captured snapshot values and Epic UE 5.9 defaults are kept separate.

Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates may be reads, writes, or initialization; address-taking references do not show value consumption. No in-game startup override or controlled gameplay test was performed.

## Evidence limits

- Short diagnostics and feature labels remain labels where the supplied help does not explain activation, output destination, or effect.
- UE 5.9 exact-name matches are upstream reference data; they do not prove the game build uses the same implementation or defaults.
- Community `var`/`ref` rows and static address references do not establish that a startup `.ini` override is accepted or changes player-visible behavior.
- Duplicate-row audit: 0 of these 25 names had differing metadata across repeated registry rows; repeated records were not counted as separate CVars.
