# Distance-field ambient occlusion CVars, batch B

This page records 19 additional `r.AO*` variables in the preserved community `var`/`ref` registry, following the related [Global Distance Field batch A](cvar-rendering-global-distance-field-batch-a.md) and [Ambient Occlusion guide](cvar-rendering-ambient-occlusion.md). The registry and `CVarDump.txt` do not identify the game build or capture method. Snapshot values below are observations, not defaults or recommendations. The local executable is Marvel Rivals Shipping build `1.1.4042190`; its precise Unreal fork/version is not established.

## How to read the local scan

Each of these names has a nonzero community `ref_rva`. The saved scan reports the instruction-candidate counts shown above, plus two address-taking hits per name. The scanner labels memory references as candidates; it does not by itself establish whether an instruction loads or stores the CVar, whether the caller is reached in a match, or what the surrounding branch means. The counts support local binary references to the registry locations, not a controlled test of startup overrides.

The community registry provides exact Unreal Engine 5.9 reference matches for some standard AO names, with defaults and descriptions shown in [`cvar-community-registry.md`](cvar-community-registry.md). Those are upstream comparison material only. Marvel Rivals' engine fork may differ, and the captured values are not defaults. Per the loader syntax supplied for this research, a `name=value` line can be expressed under `[Overrides]`; actual acceptance, priority, and visual/performance effects remain unverified.
