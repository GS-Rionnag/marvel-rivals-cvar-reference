# Lumen global-illumination CVars: batch A

This guide covers 25 exact `r.Lumen.*` entries from the preserved community registry. It combines the supplied registry/snapshot with the installed Shipping build `1.1.4042190` and Epic's published UE 5.9 CVar reference. The registry attachment has no confirmed build identity, and Marvel's exact Unreal revision is unknown; an Epic match supplies upstream engine context, not a guarantee that Rivals accepts or honors the same setting.

## Read this as editability evidence, not a preset

The `ref` rows above have local scalar loads or comparisons at the cited addresses, so they are stronger evidence of build-specific code use than a string or registration table alone. The ten `var` rows have registry entries and printable names in the local executable, but the saved scan's hits are writes to `obj_rva` storage, not direct `ref_rva` reads; do not describe those hits as proof that renderer code consumes an override. The scan can miss indirect or non-RIP-relative accesses, so “no direct read found” is not proof of unused code.

The user's loader documentation allows a `name=value` line under `[Overrides]` and says it wins over merged config. That means the syntax can express these values; it does not prove Rivals accepts each one, keeps it after later initialization, reaches the relevant path, or changes pixels. No controlled in-game override/A-B test was performed for this guide. The community snapshot is a captured value, not a default. Do not copy these values as a recommended preset; the `r.Lumen.DiffuseIndirect.Allow` and `r.Lumen.DiffuseIndirect.SSAO` rows explicitly show snapshot/upstream-default differences.
