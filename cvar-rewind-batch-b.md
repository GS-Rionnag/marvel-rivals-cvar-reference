# Rewind CVar batch B

This guide closes the exact-case `Rewind.*` family in the supplied `var`/`ref` registry. Batch A documented the first 25 names; this batch documents the remaining 13, bringing current explanatory coverage to 38 of 38 unique registered names. These are source and static-scan findings: whether the game accepts a startup override or applies a value in a live session has not been tested.

The registry row kind is `ref` for every entry below. “Snapshot” is the value recorded in the supplied registry catalog, not a recommended setting. “Epic 5.9” is the exact-name upstream reference column; `—` means no matching default was recorded there. Help text is preserved or closely summarized from the supplied community registry. It can describe intended control behavior without proving that the control is active in the shipped game.

## Evidence limits and coverage audit

- The address scan counts are static references in the named build. `direct-memory-candidate` is a scanner classification, not proof of a runtime read or write; `address-taking` records a reference to the CVar address. Neither class proves execution, direction, effective behavior, or `.ini` acceptance.
- Registry metadata has one `ref` row per name and no conflicting type/help variants across these 13 entries. The catalog snapshot is present for all 13. No exact-name Epic UE 5.9 default is recorded for any of the 13.
- The 13 names here do not overlap batch A or any earlier explanatory table. Together with batch A they cover all 38 unique exact-case `Rewind.*` names in the registered `var`/`ref` source set; none remain uncovered in that set.
- The `FXSampleHz` snapshot/help difference is reported as observed; the available sources do not explain why the snapshot is `10` while the help describes a default of `20`.
