# Sequencer CVar batch A

This guide covers the first 25 alphabetically sorted uncovered registered names whose exact, case-sensitive first dotted component is `Sequencer`. The supplied registry has 30 unique `Sequencer.*` `var`/`ref` names and no earlier explanatory-table coverage for this prefix. Five names remain after this batch.

“Snapshot” is the captured value in the supplied registry catalog, not a recommendation or proven default. “Epic 5.9 default” is the exact-name Unreal Engine reference value, separate from both the snapshot and community help. Help text describes supplied intent and is not runtime verification. Static address counts are scan classifications, not complete control-flow or data-flow analysis.

## Evidence limits and coverage audit

- The 25 names have one consistent registry row each: 8 are bool `ref`, 6 are int32 `ref`, 4 are float `ref`, 1 is FString `ref`, 1 is bool `var`, 3 are int32 `var`, and 2 are float `var`. Snapshot values are present for 24; `Sequencer.CompilerVersion` has no captured value. Exact-name Epic 5.9 defaults are recorded for 24; `Sequencer.AlwaysSendInterpolatedLiveLink` has no match in that reference catalog.
- Static scan totals are 117 `direct-memory-candidate` hits and 47 `address-taken` hits. A candidate may be a read, write, comparison, or initialization; address-taking alone is not a value access. The scan does not prove executed behavior, accepted startup overrides, or `.ini` editability.
- The batch contains the first 25 uncovered exact-case names with no overlap against existing local or public explanatory tables. There are five more registered `Sequencer.*` names after this batch.
- Snapshots and Epic reference defaults are separate evidence. For example, `Sequencer.AddKeepStateDeterminismFences` records snapshot `false` and Epic default `true`; `Sequencer.AutoTangentNew` records snapshot `1` and Epic default `2`.
