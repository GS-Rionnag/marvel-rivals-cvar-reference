# AI navigation CVar batch A

This guide documents all 23 currently uncovered registered `ai.nav.*` CVars. They cover navigation mesh generation/cache behavior, dirty-area handling, navlink matching, and diagnostics. These settings may alter AI pathing or simulation behavior; they are not graphics-quality settings.

Community help, captured snapshot values, and exact-name Epic UE 5.9 reference descriptions are separated. The community capture is unversioned. Build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`; direct-memory candidates do not reveal access direction or runtime execution. No live override or gameplay test was performed.

## Interpretation limits

- The help describes intended navigation behavior, but static matches do not show whether any setting is active in a live match or which AI actor consumes it.
- Snapshots are captured values, not recommendations. An em dash means no exact upstream default was present in the registry.
- The single `var` registration has no separate `ref_rva` field, so its object address in the scan is not proof of runtime value reads.
