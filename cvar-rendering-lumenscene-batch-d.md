## Interpretation limits

- The radiosity controls describe hardware/software ray tracing, probe evaluation, filtering, temporal accumulation, and visualization. The registry and upstream help do not establish that these features are enabled or reachable in the game.
- Surface-cache controls describe atlas capacity, capture/refresh behavior, resolution, and merging. The cited scan gives candidate references only; no complete setup function or match-time path was reconstructed here.
- Empty community help remains unresolved unless an exact Epic UE 5.9 description exists; any upstream text is labeled separately and does not prove the same behavior in Marvel Rivals.
- `var`/`ref` registry kind, captured snapshot values, and static address references do not prove that `.ini` startup overrides are accepted or change rendered output. Snapshot values are not recommendations.
