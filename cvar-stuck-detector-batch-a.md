## Build-specific context and limits

- The generated string inventory lists all eleven `StuckDetector.*` names in both Shipping executable variants. Printable-name presence does not prove runtime registration or use.
- Every registry row here is `kind=var` with `ref_rva=0`; the address-reference scan therefore has no `ref_rva` matches. Each `obj_rva` has three direct-memory candidates and one address-taking reference, which are not validated value reads or writes.
- Snapshot values are observations from `CVarDump.txt`, not verified defaults. The Epic UE 5.9 exact-name cross-check has no default for these game-specific names.
- Translation entries are unreviewed. Name-only entries are not definitions. Units, request semantics, and runtime behavior remain unknown where stated.
- No controlled runtime test established whether these names can be changed through the loader’s `[Overrides]` section or cause any observed effect.
