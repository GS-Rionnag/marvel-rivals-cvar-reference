## Practical reading

This batch mixes diagnostic names, feature gates, and server-oriented replication controls. A registered name, snapshot value, or static memory-access candidate does not prove that the user's startup `.ini` can change it. In particular, the `Net.*` prefix does not mean a client-side setting can alter server-authoritative replication. The translated help for the UID-based AOI and shared-bunch entries is unreviewed; treat its detailed mode descriptions as leads until independently confirmed.

The scan counts in the table refer only to candidates matching each entry's `ref_rva`. They are not complete control-flow traces. For `var` entries, no direct value read could be matched from the registry because the attachment provides no `ref_rva`; object-address matches are setup evidence only. No live game query, config override, or visual/network behavior experiment was performed for this batch.
