## Evidence limits

- Snapshot values are observations from `CVarDump.txt`, not verified game defaults or recommendations.
- No exact UE 5.9 default was recorded for these names in the generated community-catalog cross-check. This does not identify the game’s engine version.
- `EnableLevelOptimizationManager` uses an assistant translation of Chinese help marked unreviewed. Other meanings paraphrase the supplied help; malformed, tautological, or missing descriptions are called out.
- The dotted-name executable inventory excludes all no-dot names by design. The address scanner can still record references to registry address fields, but direct-memory and address-taking classes are unvalidated candidates, not confirmed reads or writes.
- No controlled runtime test established whether any of these entries are accepted through the loader’s `[Overrides]` section or what changes in-game.
