# General `r.*` CVar batch F: decals and default rendering features

This guide documents the next 25 currently uncovered registered names with exact first dotted component `r.`, after batches A–E and other local/public explanatory tables. The entries describe decal rendering, project-level defaults for post-processing features, and deferred uniform-expression caching.

The `var`/`ref` kinds and types come from the supplied community `console_vars.tsv`. Values in `CVarDump.txt` are a captured ShakeKill snapshot with unknown capture procedure and game build; they are not presumed defaults. Epic UE 5.9 values are exact-name upstream references and do not establish the effective Marvel Rivals settings or renderer path. The descriptions below are the supplied help, not a game test.

Static address evidence is from the Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` means an instruction matched the target address; this does not determine whether it reads or writes the value or executes during play. `address-taken` matches are reported separately. No startup override or in-game effect was tested.

## Source differences and limitations

- The snapshot differs from Epic 5.9 defaults for `r.DefaultFeature.AutoExposure`, `r.DefaultFeature.AutoExposure.Bias`, `r.DefaultFeature.LocalExposure.HighlightContrastScale`, `r.DefaultFeature.LocalExposure.ShadowContrastScale`, and `r.DefaultFeature.MotionBlur`. These are captured-value comparisons, not evidence of the game's active project defaults or rendered output.
- The `r.DefaultFeature.*` help describes engine/project defaults and explicitly says post-process volumes, camera, or game settings can override some settings. Its descriptions therefore do not establish a live visual toggle or what settings a particular game mode uses.
- `r.Decal.DecalClearInterval`, `r.Decal.EnableHitImpactApplyDecal`, and `r.Decal.ShouldSupressOverlappingStaticDecal` have no supplied help. The bool/float types and snapshot values are evidence about registry metadata and the captured snapshot only; their names are not enough to define behavior.
- The build scan has `ref_rva` matches for three `ref` entries: 3 `direct-memory-candidate` and 3 `address-taken` instructions total. The 22 `var` entries have no `ref_rva` matches; the three ref rows and 22 vars together yield `obj_rva` totals of 74 `direct-memory-candidate` and 25 `address-taken` matches. These address matches do not establish access direction, execution, or effect.
- None of these CVars is verified as accepted by the supplied startup override format or as changing Marvel Rivals in-game. No runtime test was performed.
