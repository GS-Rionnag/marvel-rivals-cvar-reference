# Rendering cache, camera, and capsule-shadow CVar batch A

This guide documents 25 exact `var`/`ref` names from the preserved community registry. It covers indirect-lighting cache controls, camera/Shake debug controls, and capsule-shadow controls. The registry attachment has no confirmed build identity; its captured values are snapshots, not proven defaults or recommended settings.

## Evidence limits and editability

The community help and kinds come from an attachment without a confirmed game build. Snapshot values are captured values, not proven defaults. Exact-name matches in the repository's Epic 5.9 cross-reference are upstream reference evidence only; they do not establish the Unreal revision or runtime behavior of Marvel Rivals. Where no exact Epic entry/help exists, this guide leaves the meaning unknown instead of inferring it from the name.

The local evidence is static analysis of the installed Shipping executable, build `1.1.4042190`. Direct scalar loads and comparisons cited above show that those code locations read the referenced value; they do not establish the full code path, whether a config override is accepted, or a visible change. For the camera-animation/shake `var` entries, saved direct-address matches are registration/object setup writes, not value reads. The scan can miss indirect accesses. No CVar was changed and no in-game test was performed.

The loader syntax can express `name=value` overrides under `[Overrides]`, but syntax alone is not proof that the game accepts or retains a particular value. Use [CVar editability and loader behavior](cvar-overrides.md) when evaluating whether a specific entry is safely editable.
