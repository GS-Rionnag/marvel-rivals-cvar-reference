# Physics general and movement CVar batch N

This guide documents the final 18 distinct registered `p.*` names not already covered by explanatory CVar tables in the local docs or public reference repository. Together with batches A–M, this closes the 1043-name `p.*` `var`/`ref` registry inventory found in the supplied community registry. Names are deduplicated across registry rows. Community help records the source author’s stated purpose; it does not confirm live behavior.

Snapshot values come from the supplied `CVarDump.txt`. Epic UE 5.9 defaults and descriptions are exact-name upstream references, not confirmed game-build defaults. Static address candidates come from Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates can represent reads, writes, comparisons, or initialization; address-taking matches alone do not establish a value read. No runtime or startup-override test was performed.

## Interpretation limits

- Registry membership and snapshot data do not establish that the game accepts a startup `.ini` override or that a player can edit the setting.
- Community help is reported as supplied; any Chinese translation is labeled unreviewed. Epic descriptions/defaults are separate upstream evidence.
- Static address matches are not complete runtime traces. No match in the scan does not prove a CVar is unused.
