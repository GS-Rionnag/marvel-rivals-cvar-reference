## Interpretation limits

- The detailed scheduler and diagnostic help describes intended controls; it does not prove the supplied code path runs for every monster or mode.
- An exact Epic UE 5.9 match is an upstream reference only. A missing match does not establish that the game has no default.
- Registry presence and static addresses do not establish player-facing editability, startup `.ini` acceptance, or runtime behavior.
- Conflicting repeated registry metadata: 0. Repeated registry rows are counted once per exact name.
