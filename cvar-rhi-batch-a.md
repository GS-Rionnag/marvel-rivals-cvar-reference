# RHI CVar batch A

This guide documents all 13 currently uncovered exact-case `RHI.*` names in the community `var`/`ref` registry. `RHI.MaximumFrameLatency` is already covered in [CVar overrides](cvar-overrides.md), so it is not duplicated here. The complete registry family contains 14 names.

The supplied registry and snapshot are community artifacts with unconfirmed build alignment. Their `var` and `ref` labels, captured values, and an exact Unreal Engine 5.9 reference match do not prove that Marvel Rivals accepts a startup `.ini` override or that changing a value has a runtime effect. The installed executable is build 1.1.4042190; scanner matches below are static candidates only.

## Reading the evidence

- `Snapshot` is the value captured in `CVarDump.txt`; it is not necessarily the engine or game default.
- `Epic UE 5.9 default` is included only when the exact name matched the generated UE 5.9 comparison. A dash means no exact value was recorded there. It does not identify the game’s engine version.
- The help text is supplied by the community CVar attachments. Interpretations above paraphrase those descriptions; they do not claim game-specific runtime behavior.
- The binary scan searched for references to the registry address fields. A direct-memory candidate is an instruction classified by the scanner as a possible memory access; an address-taking reference may only take or pass an address. Neither class was control-flow validated for this guide.
- `RHI.FeatureSetLimit` help explicitly says changing the setting at runtime has no effect. This does not establish which startup overrides the game accepts.
- Whether any row is writable through this mod loader’s `.ini` override mechanism is unverified. No controlled runtime change was performed.
