## Evidence limits

- The supplied community registry marks every row as `ref`, not `var`; reference rows do not establish runtime registration or override support.
- `CVarDump.txt` values are a captured snapshot, not defaults or recommendations.
- No exact-name Epic UE 5.9 reference match appears in the build inventory. This is not evidence of the game’s precise engine version.
- Printable names establish string presence only. The `ref_rva`/`obj_rva` scan counts are static address-reference candidates, not validated reads, writes, or proof of execution.
- No controlled test established whether these names can be set through `[Overrides]` or how they affect live gameplay.
