## Interpretation limits

- Help strings and upstream references describe intended ability, cost, prediction, and scope controls. Where neither provides an explanation, the table says so rather than interpreting the name.
- Exact-name UE 5.9 data is upstream context, not proof of Marvel Rivals’ engine implementation or effective defaults. Snapshots are observations, not recommendations.
- Repeated registry rows are de-duplicated by exact name. The duplicate-row audit checks whether kind/type/help records disagree; differing object addresses alone do not create separate CVars.
- Static reference counts are not complete data-flow or runtime traces. They do not prove accepted `.ini` overrides, live use, or a particular ability/gameplay effect.
- Duplicate-row audit: 0 selected names have conflicting kind/type/help records (33 source rows across 25 names). Snapshot cross-check: 0 conflicting values; 3 names have no captured value in `CVarDump.txt`.
