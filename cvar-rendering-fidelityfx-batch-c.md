## Interpretation limits

- These FSR3 controls describe reactive-mask shaping for roughness, translucency, TAA response, and shading changes, plus sharpening, upsampling, and platform/backend choices. The descriptions express intended behavior, not evidence that FSR3 is active in a Marvel Rivals match.
- An exact UE 5.9 default is an upstream reference, not proof of the game’s effective setting. Captured snapshot values are not recommendations.
- A static address candidate does not establish the path executes, the setting is writable from startup configuration, or what visual/performance change it causes.
- Duplicate registry-record audit: 0 selected names had conflicting kind/type/help metadata. Snapshot cross-check against the attached dump: 0 mismatches.
