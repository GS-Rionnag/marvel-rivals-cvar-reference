## Interpretation limits

- Help describes replay fast-forward behavior, recording prioritization, package-map loading, and hologram replay transport/mode settings where available. Chinese text keeps the source and an explicitly unreviewed rendering together.
- The captured value for `demo.ForceDisableAsyncPackageMapLoading` is `1`, while the exact-name Epic UE 5.9 default is `0`. This difference is recorded, not treated as a recommendation.
- These variables may affect replay and network behavior rather than ordinary graphics quality. Names and registration do not show which branch the retail match uses or whether the loader accepts an override.
