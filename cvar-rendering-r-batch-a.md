# General `r.*` CVar batch A: render state and Composure

This guide documents the first 25 alphabetically sorted uncovered registered names with the exact `r.` first component, after reviewing public and local explanatory tables. The entries span global-distance-field and sky lighting, material/texture diagnostics, translucency and GBuffer clearing, shader configuration, and Composure compositing target management.

The community dump’s `var` and `ref` labels are registration metadata only. Snapshot values are captured observations. Exact-name Epic UE 5.9 references are upstream documentation, not confirmed Marvel Rivals defaults or proof that those code paths are active.

Build address evidence comes from static scanning of Marvel Rivals Shipping build `1.1.4042190`. The scan’s `direct-memory-candidate` class is not directionally interpreted; it may be a read, write, comparison, or initialization. `address-taken` references are counted separately. No function execution, config override, or in-game output was tested.

## Source and behavior limits

- The cloud/global-distance, material, sky, and translucency descriptions above are the supplied registry help or exact UE 5.9 reference text. They do not establish that a corresponding rendering path is active in this game build.
- The Composure entries describe target-pool diagnostics, pass-list management, active rendering, opacity handling, and intermediate-target reuse. Their names/help do not show whether Marvel Rivals uses Composure.
- `r.CompileMaterialsForShaderFormat` has an FString type and no captured snapshot/default value; the help describes additional shader-format compilation for inspection, with temporary shader output. No string value or use case is inferred.
- A registered `var`/`ref`, upstream default, or static address match does not prove startup override acceptance or a visible/gameplay effect.
