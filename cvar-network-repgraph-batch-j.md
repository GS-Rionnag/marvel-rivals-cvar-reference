# Replication Graph CVars: RepGraph batch J

This batch covers 25 registered `Net.RepGraph.*` variables that were not already explained in a focused guide. The descriptions below use the preserved community registry help and captured CVar snapshot. The snapshot’s build and collection method are unknown, so its values are observations, not verified defaults or recommendations.

The local address scan targets the main Shipping executable from game build `1.1.4042190`. A direct-memory candidate means an instruction references the registry's `ref_rva`; it is useful evidence that code touches the value, but the scan does not by itself establish the surrounding control flow, runtime effect, or whether a startup override is honored. `obj_rva` setup/address references alone are weaker and are not counted as proof of a value read. Server-focused Replication Graph controls may not be client-effective.

## What this establishes

The registry supplies behavior descriptions for many of these entries, while the binary scan independently finds direct reference-value accesses for only a subset. The captured values are a separate snapshot and should not be treated as engine defaults. These records do not prove that a local configuration override is accepted, that an effect runs in the client process, or that it can affect server-authoritative replication. Verify any proposed override in an isolated offline/editor environment before drawing runtime conclusions.
