# HairStrands CVar batch F: streaming and visibility rendering

This batch records the next 25 alphabetically sorted currently uncovered `r.HairStrands.*` variables after published batches A–E and every other explanatory guide. It includes strand streaming, velocity and rasterization behavior, lighting/visibility, visualization, and tile/rasterizer sizing controls. Names were selected from the current public documentation set.

Community `var`/`ref` classifications and supplied help describe the source dump; they do not establish that a Marvel Rivals startup override is accepted or changes a live match. Snapshot values are read directly from the supplied `CVarDump.txt`. Exact-name Epic UE 5.9 entries are separate upstream references, not confirmed game defaults.

Static address evidence is from the scan of Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` and `address-taken` matches are kept distinct. A candidate may be a read, write, comparison, or initialization; this scan is not a control-flow or runtime trace.

## Source disagreements and limits

- `r.HairStrands.SwapType` help states default `1` while its captured snapshot is `3`; no exact Epic 5.9 default is listed.
- `r.HairStrands.SkyLighting.IntegrationType` help is incomplete: it lists modes 0 and 1 only, so other enum values and their semantics are unknown.
- `r.HairStrands.Visibility.Compute.MeanSamplePerPixel` help says the default is 0.5, while the exact Epic 5.9 field and snapshot are 0.75.
- `r.HairStrands.Visibility.ComputeRaster.MaxTiles` help says 8192 is the default, while the Epic 5.9 field and captured snapshot say 65536. This conflict is retained rather than resolved by assumption.
- `r.HairStrands.VelocityThreshold` help says a default of 3, while the Epic 5.9 field and snapshot say 1.
- A setting registered as `var` has no `ref_rva` value-use candidate in this scan. For every row, address references alone do not prove override support or gameplay effect.
- Snapshot values are observations, not recommendations. No CVar override or in-game visual/performance comparison was run.
