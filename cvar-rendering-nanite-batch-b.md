## Interpretation limits

- The descriptions identify intended controls such as material warnings, depth export, tile clears, visibility/material handling, and candidate limits. They do not establish whether each feature is active or supported in this game build.
- Where the community help is empty, a CVar name or upstream reference is not used as a replacement definition; the behavior remains unresolved.
- A static `ref_rva` candidate does not show whether code reads or writes the value, and object-address references can come from registration/setup. Neither is proof of execution in a match.
- `var`/`ref` registry kinds, snapshots, and binary references do not establish that an `.ini` override is accepted or changes rendered output. Snapshot values are not recommendations.
