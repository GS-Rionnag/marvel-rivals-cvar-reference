# General `r.*` CVar batch G: lighting, shadows, and render setup

This guide documents the first 25 currently uncovered registered names with the exact first dotted component `r.`, using the current local/public explanatory-table row union after batches A–F. Topics include ambient occlusion, capsule shadows, bloom and depth-of-field quality, D3D presentation options, render-graph task timing, and diffuse-indirect denoising.

The supplied `console_vars.tsv` `var`/`ref` kind and type are registry metadata. Values in `CVarDump.txt` are a captured ShakeKill snapshot with unknown capture method and build, not documented defaults. The Epic UE 5.9 values are upstream references and do not prove what Marvel Rivals applies. Community help is quoted or summarized as source text, not independently validated.

The static address-reference scan targets Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` matches do not identify whether an instruction reads, writes, or initializes the target and do not prove execution. `address-taken` references are reported separately. No startup override acceptance or in-game effect was tested.

## Source differences and limits

- Snapshot values differ from Epic 5.9 defaults for `r.AllowStaticLighting`, `r.AmbientOcclusionLevels`, `r.AmbientOcclusionRadiusScale`, `r.BloomQuality`, `r.CapsuleDirectShadows`, `r.CapsuleIndirectShadows`, `r.CapsuleShadows`, and `r.DepthOfFieldQuality`. The snapshot is not established as a default or an effective game value.
- `r.D3D11.UseAllowTearing` and `r.DeformerGraph.Enable` have no exact Epic 5.9 default in the catalog. `r.DiffuseColor.Max` and `r.DiffuseColor.Min` are explicitly described as non-Shipping test settings, which makes the runtime significance of their captured values particularly uncertain.
- The scan records `ref_rva` candidates for 11 `ref` rows: 25 `direct-memory-candidate` instructions and 11 `address-taken` hits in aggregate. The 14 `var` entries have no listed `ref_rva` candidates. Across all 25 entries, `obj_rva` totals 61 `direct-memory-candidate` and 29 `address-taken` hits. No control flow or execution was established by these matches.
- Registration metadata, upstream help, or a static address match does not establish startup override acceptance, writability, or a visible effect in Marvel Rivals. No runtime test was performed.
