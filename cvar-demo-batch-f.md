- An exact UE 5.9 match is upstream reference data, not proof of Marvel Rivals’ engine implementation or effective default. Snapshot values are observations, not recommendations.
- Static address candidates do not prove a branch is executed in a match, a replay feature is active, or a startup `.ini` override is accepted.
