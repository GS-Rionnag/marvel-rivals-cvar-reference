# Additional public config name audit

This note records exact CVar-shaped spellings found across three additional public config/community sources checked during the audit. A config assignment is evidence only that its author published the spelling and value; it does not establish that the game registers the name or applies the setting.

| Exact source spelling | Source evidence | Cross-check | Assessment |
|---|---|---|---|

The Steam guide is currently marked removed/incompatible on Steam. Natram's file is pinned to commit [`b243da3`](https://github.com/Natram1zh/Marvel-Rivals-Config/commit/b243da3aee605f80ca0e6abfa383793c069a46b9). These source conditions and the lack of runtime tests limit the findings to name-presence evidence.

## Scope and counting

The distinct unverified outside-registry candidate count is now 115: the prior 114 plus `r.Shadow.RadiusThresholdRSM`. The two source spellings that case-fold to already registered canonical names are recorded for auditability but do not add distinct candidates. Raw case-sensitive community strings are separate from the candidate count.
