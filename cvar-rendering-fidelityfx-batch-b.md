This guide covers the next 25 alphabetically sorted registered `r.FidelityFX.*` names after [batch A](cvar-rendering-fidelityfx-batch-a.md), chosen from the remaining `var`/`ref` entries. It focuses on FSR3 accumulation, quality, reactive masks, and temporal-history controls. Community help, captured `CVarDump.txt` values, and exact-name Epic UE 5.9 reference defaults are kept distinct. The community attachments do not identify the game build or capture method.

Build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` indicates possible value access, but does not say whether an instruction reads, writes, or initializes the setting. Address-taking references do not prove value consumption. No function body, runtime config override, or in-game visual comparison was performed.

## Interpretation limits

- FSR3 help describes intended controls for accumulation, disocclusion, reactive masks, stencil selection, and temporal history. It does not show that the game enables FSR3 or that changing these controls affects the current render path.
- Exact-name UE 5.9 reference entries are upstream context only. Snapshot values are observations from the supplied dump, not confirmed game defaults or recommendations.
- Address-reference candidates are not a runtime trace. They do not establish that `.ini` overrides are accepted, that any path executes, or what visual or performance change a value causes.
