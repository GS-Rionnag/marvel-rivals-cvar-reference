# Virtual Texturing CVar batch A

This guide covers the first 25 alphabetically sorted currently undocumented registered `r.VT.*` variables. Community help records intended controls; upstream UE 5.9 values are exact-name references, and the separate snapshot is a captured observation. Neither proves the active Marvel Rivals renderer path.

Static address candidates are from Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates do not tell whether a reference reads, writes, compares, or initializes the value; object-address matches do not demonstrate consumption. No controlled startup override or visual test was performed.

## Interpretation limits

- A help description of texture page pools, physical memory, uploads, or streaming does not establish a performance change or visual effect in Marvel Rivals.
- Snapshot values are not defaults; an absent Epic reference match means no exact-name match in the comparison catalog.
- Registration and address candidates do not prove player editability, `.ini` acceptance, or runtime use.
