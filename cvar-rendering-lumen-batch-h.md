# Lumen Screen Probe tail and Translucency Volume CVar batch H

This batch covers the final 12 uncovered `r.Lumen.ScreenProbeGather.*` entries and the first 13 uncovered `r.Lumen.TranslucencyVolume.*` entries in registry order. Community help, Epic UE 5.9 reference descriptions, and snapshot values are kept distinct. The community registry does not identify its game build or capture method; an upstream match does not prove the game uses the same engine revision or behavior.

Build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate may be a read, comparison, or write; a CVar-object reference may be registration/setup code. Static references do not prove the code runs in a match. No controlled `.ini` override, live CVar query, or in-game A/B test was performed.

## Interpretation limits

- The last 12 Screen Probe entries include debug/visualization controls, mesh-SDF tracing, probe tracing resolution, temporal filtering, foliage backface gathering, and wave-op selection. Descriptions explain intent, not whether each path is enabled by the game.
- The Translucency Volume rows document enable/range/grid controls, hardware ray tracing, ray-intensity settings, and radiance-cache selection/allocation. Several have no explanatory help; those are explicitly marked as unresolved rather than assigned a name-based definition.
- Snapshot values are captured values, not defaults or recommendations. Exact Epic 5.9 defaults are shown separately where available; an `—` means there is no exact default entry in this registry.
- Address matches are not a runtime trace. This batch does not establish that these CVars accept overrides or affect a live match.
