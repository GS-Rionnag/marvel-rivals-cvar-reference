# Epic CVar reference entries found in the game binaries but absent from the community variable registry

These names match Epic's Unreal Engine 5.9 CVar reference exactly and were found as printable strings in the local build scan, but they have no `var` or `ref` row in `console_vars.tsv`. This supports their meaning as engine CVar names and their presence in the scanned binary set; it does not prove that Marvel Rivals registers or honors them at runtime. Entries also present in `CVarDump.txt` are marked with their snapshot value.

- Engine source: [Epic Unreal Engine 5.9 Console Variables Reference](https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-console-variables-reference).
- Local scan: build `1.1.4042190`, 126 executables/DLLs; see [full inventory](EVIDENCE.md#build-specific-static-analysis).
- Exact-name entries: 49; also in the community value snapshot: 21; not in that snapshot: 28.
