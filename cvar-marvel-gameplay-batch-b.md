# Marvel gameplay and diagnostics CVar batch B

This guide covers the first 25 remaining registered `Marvel.*` CVars after the existing game-specific embedded-text and ability-event guides. Entries are taken in registry order. Community help and snapshot values are not confirmed game defaults; no exact Epic UE 5.9 default is available for these names in the supplied reference table.

The build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate may be a read, comparison, or write; an object reference for a `var` may be registration/setup. Static matches do not prove runtime consumption or that a config override is honored. No live console query or controlled in-game test was performed.

## Interpretation limits

- These entries include diagnostics, ability/projectile paths, camera behavior, health-bar display, asset streaming/residency, character-specific switches, and performance-related logging. Some may affect gameplay, networking, or testing behavior rather than visual quality.
- Community help describes intended behavior but does not establish safe ranges, code-path conditions, or whether the retail game consumes the setting. Chinese translations are marked unreviewed where used.
- Snapshot values are from an unversioned community capture, not recommendations or confirmed defaults. A `—` Epic default means there is no exact upstream default in the supplied reference.

For the registry and capture caveats, see the [community CVar registry](cvar-community-registry.md). The static evidence is a candidate only and should be revalidated against a current build before changing values.
