# Animation-system CVar batch E

This page documents the next 25 uncovered `a.*` entries in the supplied community registry. They cover animation evaluation and scheduling, notifies, locomotion, hit reactions, and a game-specific destruction IK feature. The table separates the registry's help and captured values from static build evidence. Snapshot values come from an attachment with unknown build and collection method; they are observations, not verified defaults or recommendations.

The saved address scan targets Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate against `ref_rva` indicates that an instruction accesses the CVar's value storage. It does not identify the full branch, prove execution during a match, or establish that a startup `.ini` override is accepted. `obj_rva` setup/address matches are not counted as reads of the current value.

## What this establishes about overrides

The `ref` rows with direct-memory candidates show that this build has instructions accessing those CVar value addresses. For `var` entries, the saved scan's object-address matches do not prove that the current value is read by the animation or IK feature. Neither kind of evidence proves that a local startup `.ini` override is accepted, wins over later config layers, or produces a visible effect. No controlled override, animation comparison, or live-game test was performed for this batch.
