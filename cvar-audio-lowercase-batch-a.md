## Evidence limits

- Snapshot values are observations from the supplied `CVarDump.txt`, not verified game defaults or recommendations.
- The Epic column shows only exact-name UE 5.9 reference matches. A dash means no default was recorded in the cross-check; it does not establish the game’s engine version.
- Only `EnableAudioCluster` and `EnableHitCluster` have useful supplied help among these rows. The other descriptions are unknown where marked; a variable name alone is not enough to establish function.
- Address-scan counts are candidate instructions referencing registry `ref_rva`/`obj_rva` fields. They were not control-flow-validated and do not prove runtime reads, writes, registration, override acceptance, or effect.
- No controlled runtime change tested whether the loader accepts these entries through `[Overrides]`.
