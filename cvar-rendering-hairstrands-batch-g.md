# HairStrands CVar batch G: visibility rasterization and voxelization

This batch documents the next 25 alphabetically sorted `r.HairStrands.*` entries absent from the current public guides after batches A–F. It covers software/hardware hair rasterization, per-pixel linked-list compositing, MSAA sample settings, coverage thresholds, and voxelization density inputs.

The source registry’s `var`/`ref` kind is not proof of player-facing editability. The snapshot column is taken from `CVarDump.txt`; Epic UE 5.9 defaults come from exact-name upstream reference matches. Neither is asserted to be the game’s effective default.

Build findings are static address-reference matches from Marvel Rivals Shipping build `1.1.4042190`. The scan’s literal `direct-memory-candidate` and `address-taken` classes are distinguished. A candidate is not a traced read or executed path; config acceptance and gameplay impact were not tested.

## Source differences and limits

- `r.HairStrands.Visibility.MSAA.MeanSamplePerPixel` help states a default of 0.5, while the exact Epic 5.9 default and snapshot are 0.75.
- `r.HairStrands.Visibility.MSAA.SamplePerPixel` has a snapshot of 1, while the Epic 5.9 default is 4 and the supplied help lists 2, 4, or 8. The source does not explain this discrepancy.
- Several controls are described as experimental or specify particular rasterization paths. Help and address references do not establish whether those paths are selected or usable in Marvel Rivals.
- Captured snapshot values are not recommendations. The data does not prove that any CVar accepts a startup `.ini` override or changes rendered output.
