# Lumen ReSTIR Final Gather CVars: batch A

This page documents the first 25 uncovered registered `r.Lumen.ReSTIRGather*` variables. Every exact name has an Unreal Engine 5.9 reference match in the preserved registry cross-reference. Upstream help/defaults describe Unreal's control surface; they do not prove Marvel Rivals uses that exact engine implementation or enables the experimental renderer path.

`ReSTIRGather` is documented as a prototype alternative to `LumenScreenProbeGather`, disabled by default because the help says its current quality is much lower and it supports fewer features. The other settings cover trace/reservoir resolution, spatial and temporal reuse, denoising, short-range AO, and reconstruction to full-resolution irradiance. Where the reference has no help, the name/default is not enough to infer its effect.

Every community snapshot value in this batch matches the exact UE 5.9 reference default. The snapshot's game build and collection method are unknown, so that agreement does not establish the live Marvel Rivals defaults. The saved scan targets Marvel Rivals Shipping build `1.1.4042190`.

## What the local build scan establishes

- The top-level `r.Lumen.ReSTIRGather` row is a `var`. The saved scan found an object/setup reference, but no direct value-read candidate. For the 24 `ref` entries below it, the scan found at least one direct-memory candidate at the recorded `ref_rva`. Those are instruction-level storage-access candidates, not end-to-end control-flow traces or proof that the ReSTIR path is enabled.
- A `var`/`ref` row, matching UE help, snapshot value, or direct memory access does not prove that the game's startup `.ini` loader accepts an override or that it wins later config layers. No live console query, controlled `.ini` override, or in-game image comparison was performed for this batch.
- The page's explanation of each setting follows the UE 5.9 reference help; its visible effect in Marvel Rivals remains untested. The main enable switch's help itself warns that ReSTIR Final Gather is experimental and lower quality than Lumen Screen Probe Gather.
