# HairStrands CVar batch E: simulation, sky lighting, and streaming data

This batch documents the next 25 alphabetically sorted currently uncovered `r.HairStrands.*` variables after the published batches A–D and the other explanatory guides. It covers shadow rasterization, hair simulation, sky ambient occlusion and lighting, BSDF integration inputs, strand rendering/width, and strand bulk-data behavior.

The registry marks entries as `var` or `ref`; these kinds describe the source dump and do not prove that a game config override is accepted or has an effect. Values in the snapshot are captured observations. Exact-name Epic UE 5.9 entries are upstream references, not confirmed game defaults.

Static scan evidence is from Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` and `address-taken` hits are reported separately; candidates can be reads, writes, comparisons, or initialization. The saved scan is not a complete function trace or runtime observation.

## Interpretation and source gaps

- The community help for `SkyAO.SampleCount` says its default is 16, while the catalog’s exact Epic 5.9 field gives 4 and the captured snapshot is also 4. These are separate source statements; the guide does not pick one as the game’s effective default.
- The supplied `SkyLighting.IntegrationType` help lists `0: Adhoc` and `1: Uniform` but is cut off after that; other enum values and semantics remain unknown.
- Simulation and strand-rendering variables marked `var` have object-address scan evidence but no registered `ref_rva` value-consumption evidence in this scan. Their descriptions do not prove an in-game change.
- Snapshot values are not recommendations. Even where a CVar is referenced by code, this evidence does not prove startup `.ini` acceptance or a visual/runtime result.
