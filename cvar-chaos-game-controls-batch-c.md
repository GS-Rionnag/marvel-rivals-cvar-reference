# Chaos game-specific controls, batch C

This page covers 25 `p.Chaos.*` entries from the community `var`/`ref` registry. They concern trace animation, transition framing, Geometry Collection (GC) rendering and tick controls, break-event filtering, and several poorly described switches. The registry and snapshot do not identify their capture build or method. Snapshot values below are observations, not defaults or recommendations. None of these names has an exact Epic 5.9 CVar-reference match in the generated registry catalog.

Local code evidence comes from the saved RIP-relative address scan for Marvel Rivals Shipping build `1.1.4042190`. Direct comparisons or loads against a `ref_rva` are evidence that compiled code reads the referenced storage; they do not reconstruct the complete feature behavior or prove the path runs in a normal match. `obj_rva` setup hits and address-taking instructions alone are not value reads. No runtime override or gameplay test was performed.

## Evidence and limitations

- Exact names, types, help, and reference metadata are in [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322); captured values are in [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452). The snapshot capture build and collection method are unknown, and values are not defaults.
- Direct instruction candidates come from [`build-4042190-cvar-address-hits.tsv`](EVIDENCE.md#evidence-artifacts-not-included). Most listed sites are comparisons or loads of a `ref_rva`; `GCEditorPhysics` has no direct value-read candidate, and `GCResetLevel`, `GCUseISM`, and `GCUseISMToCastShadow` are `var` rows without `ref_rva` fields. Static access does not prove startup-override acceptance or normal-match execution.
- The community catalog has no exact Epic 5.9 reference match for these names. Names and help therefore come from game/community metadata; translation and opaque implementation details remain uncertain.
- Per the example loader syntax, these values can be expressed as `name=value` lines under `[Overrides]`. No test here establishes that the game accepts them, applies them, or changes behavior. See [CVar override evidence levels](cvar-overrides.md#does-a-cvar-actually-change-in-marvel-rivals).
