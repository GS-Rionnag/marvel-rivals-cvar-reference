# Voice and VOIP CVar batch A

This guide covers all 16 currently uncovered registered `voice.*` variables in the supplied community registry. The names control or describe microphone capture, VOIP buffering and playback, and one general audio-engine output switch. Their help text gives intended meanings; it does not establish which Marvel Rivals subsystems use them or whether an `.ini` override is accepted.

The dump snapshot is a captured value, not a verified game default. The Epic UE 5.9 values are upstream reference defaults, not proof of defaults in Marvel Rivals. Build evidence comes from static address matches in Shipping build `1.1.4042190`; the scan did not trace the access direction, callers, or runtime effect. No controlled override or in-game VOIP test was performed.

## Interpretation limits

- The help strings and exact Epic UE 5.9 matches describe intended or upstream behavior; they do not confirm Marvel Rivals runtime behavior.
- Snapshot values are not recommendations or verified defaults.
- The static scanner matches addresses from registry metadata in the executable's `.text`. A direct-memory candidate may read, write, compare, or initialize data; an address-taking instruction is not itself a read. The scan is triage, not control-flow analysis.
- Registry presence and binary address matches do not prove that a player can set a CVar in the startup `.ini`, that the override wins at launch, or that changing it is safe for networked play.
- No controlled startup override, microphone loopback, VOIP latency measurement, or audio-engine mute test was performed.
