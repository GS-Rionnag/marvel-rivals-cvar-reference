# Jarvis CVar batch A

This guide covers all 14 currently uncovered, exact-case `jarvis.*` `var`/`ref` entries. The supplied help points to demo recording, CSV profiling, replay stop behavior, and UI replay/widget-event diagnostics. Several UI and streamer names have no useful help, so their exact effects remain unknown. The community registry does not identify its capture build.

No entry has an exact-name Epic UE 5.9 CVar match. Snapshot values are captured observations, not documented defaults. The local build inventory contains the names and nearby replay-related strings, but string proximity alone does not prove which setting controls a function. Static scan counts below are candidates for the registry's `ref_rva` and `obj_rva` fields, not proof of value reads/writes or executed behavior. `.ini` editability remains untested.

## Interpretation limits

- The help distinguishes battle/demo recording, UI replay, CSV profiling, and replay-stop behavior, but does not define each feature's supported game modes, storage format, or data collection scope.
- Several UI settings have names that sound like fixes or selection policies, but there is no supplied help with enough detail to explain their exact branch behavior.
- Static strings establish name/text presence in the scanned build only. Nearby text, including UJarvis replay function names and widget-event/upload text, is not a substitute for tracing the code path.
- No controlled runtime test changed these entries. Registry presence and snapshot values do not establish that the loader's `.ini` override mechanism accepts them.
