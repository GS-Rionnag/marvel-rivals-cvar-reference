# Audio stream-cache and priming CVars

This guide covers all 27 currently uncovered registered `au.streamcache.*` and `au.streamcaching.*` variables in the supplied community registry. The descriptions below summarize registration help; they are evidence of intended controls, not proof that Marvel Rivals consumes a changed value. Snapshot values are captured values, and Epic UE 5.9 defaults are upstream references only.

The build column reports static address-reference scan candidates in Marvel Rivals Shipping build `1.1.4042190`. A candidate is not a traced load or executed call path; the scan does not show whether an address is read or written, nor whether an `.ini` startup override is accepted. No live config experiment or gameplay test was performed.

## Interpretation limits

- Several labels describe memory, loading, cache trimming, or profiling behavior. The table records what the supplied help says; it does not claim the relevant UE code path is active in the game build.
- Upstream matches can explain the engine-level concept, but they do not establish Marvel Rivals version alignment or runtime use.
- `var` and `ref` are source-dump categories, not a guarantee of player-facing editability. A snapshot is not a recommendation, and static address hits alone do not establish accepted config overrides.
