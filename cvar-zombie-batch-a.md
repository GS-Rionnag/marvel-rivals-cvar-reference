## Limits

- Snapshot values come from `CVarDump.txt`; they are observations, not verified defaults or recommendations.
- A dash in the Epic column means no exact UE 5.9 default was recorded for that name in the community-catalog cross-check. The game build does not declare its exact Unreal version.
- The help translation table marks the English descriptions as unreviewed. Rows without supplied help are not defined from the name alone; any name-based interpretation is labelled as an inference.
- Static scan classifications are candidates from references to the registry `ref_rva`/`obj_rva` fields. The scans do not establish registration, value reads, call paths, execution, override acceptance, or effects.
- Whether the loader accepts any of these through `[Overrides]` is unverified. No controlled runtime change was performed.
