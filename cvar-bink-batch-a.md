These intended meanings do not prove that the game honors a startup override.

## Evidence limits

- Snapshot values are observations from `CVarDump.txt`, not verified game defaults or recommendations.
- No exact UE 5.9 default was recorded for these plugin-specific names. This comparison does not establish the game’s engine version.
- Printable names in the game executables establish string presence only, not runtime registration or code execution. Address-scan classifications are candidate references to registry fields, not validated reads or writes.
- `bink.UseManagedPlayerTick` help explicitly says startup-only and restart-required; this is community-supplied help, not a successful test of this loader’s behavior.
- No controlled runtime test established whether these entries are accepted through the loader’s `[Overrides]` section or what effect changing them has.
