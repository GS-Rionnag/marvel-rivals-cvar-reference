This page covers 25 `p.Chaos.*` registry entries for broadphase batching, particle bookkeeping, debug output, recovery, and solver setup. The community registry does not state its capture build. Snapshot values below are observations, not verified defaults or recommendations. Build-specific instruction evidence refers to Marvel Rivals Shipping build `1.1.4042190`.

## Evidence and editability limits

- All 25 names exactly match `var`/`ref` entries in the preserved registry. Twenty-four are `ref` rows; `p.Chaos.Simulation.ApplySolverProjectSettings` is a `var` row. No Chinese-help translation entry was found for this batch.
- Snapshot values come from `CVarDump.txt`; the capture build and method are unknown. They are not treated as game defaults or recommendations.
- The binary address-reference scan found direct `ref_rva` memory instructions for 20 entries. Five have only address/setup hits or no `ref_rva` value-read evidence: `PBDLongRangeConstraints.MinParallelBatchSize`, `RecoveryReplay`, `ReplayTest`, `Simulation.ApplySolverProjectSettings`, and `StopRpcSync`. A direct instruction candidate supports access to the value but does not prove that the branch runs in a match or that the loader's requested value reaches it.
- Help for the three broadphase batch-size entries is identical or near-identical. Treat that as a metadata limitation; do not assume the controls are aliases or share the same exact processing unit.
- The example `[Overrides]` syntax can express a value for these names, but this page has no runtime config-acceptance or controlled behavior test. Registration metadata and static reads alone do not prove an override is honored or visibly changes gameplay.
