# Garbage collection CVar batch A

This guide documents the first 25 currently uncovered exact lowercase `gc.*` registered names after checking local and public explanatory guides. The registry contains 37 distinct `gc.*` `var`/`ref` names; 3 uncovered names remain after this batch. Inventory-only cross-check tables were not counted as explanatory coverage.

Community help records the source author’s stated purpose and does not establish current game behavior. Snapshot values come from `CVarDump.txt`; Epic UE 5.9 defaults and descriptions are exact-name upstream references, not confirmed game-build defaults. Static address matches come from Shipping build `1.1.4042190`. Direct-memory candidates may be reads, writes, comparisons, or initialization; address-taking matches alone do not establish a value read. No runtime or startup override test was performed.

## Interpretation limits

- Registry membership and snapshot presence do not establish startup `.ini` acceptance, player editability, or a live game effect.
- Epic references are upstream exact-name matches; version alignment with the game build is unconfirmed.
- Static address matches are not complete value-use traces. Missing scan hits do not prove a CVar is unused.
