# Path Tracing CVar batch B

This guide covers the next 25 alphabetically sorted currently undocumented `r.PathTracing.*` variables after batch A. Supplied help, captured values, and Epic UE 5.9 exact-name reference defaults are recorded separately; these sources do not prove path tracing is active in Marvel Rivals.

Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates may be reads, writes, comparisons, or initialization, and address-taking does not establish value consumption. No controlled config launch or rendered-image comparison was performed.

## Interpretation limits

- Some settings describe experimental sampling, caustics, denoising, or materials; help does not prove the game’s renderer uses those paths.
- Epic defaults are upstream references only. A missing match and an empty help field are left unresolved.
- A registered CVar and static address references do not prove `.ini` editability, acceptance, or in-game effect.
