# Rendering shadow CVar batch E

This page documents the next 25 uncovered `r.Shadow.*` entries in the community registry. The captured values are observations from an attachment with an unknown game build and collection method; they are not verified defaults or recommendations. Exact-name Unreal Engine 5.9 matches are upstream context and do not prove that Marvel Rivals uses the same implementation or enables that renderer path.

The local scan targets Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate is an instruction-level access to a registered CVar value address, not a complete control-flow trace. It does not prove that the setting is consulted in an ordinary match or that a startup `.ini` override is accepted.

## What the build scan establishes

Six of the 25 names have direct `ref_rva` access candidates in the scanned build: `PreshadowsForceLowestDetailLevel` (six comparisons), `RecordInteractionShadowPrimitives` (one comparison), `RemappingDFShadowFactorMax` and `RemappingDFShadowFactorMin` (one float load each), `ResolveLightRelevanceDynamicByCastShadow` (two comparisons), and `ScalableShadowMapRange` (one float load). The other 19 names have no direct value-read candidate in this scan. A missing match is not proof of an unused setting; indirect accesses and code outside the scanned executable can be missed.

All 25 names have `var` or `ref` rows in the community attachment. Registration labels, matching UE 5.9 help, captured values, or static value-address accesses do not prove that a local startup `.ini` override is accepted, wins over later configuration layers, or changes a live match. No controlled override or in-game shadow comparison was performed. Snapshot values should not be copied as a preset.
