Captured snapshot values and exact-name Epic UE 5.9 defaults are separate. Build address candidates come from static scanning of Shipping build `1.1.4042190`; direct-memory candidates do not distinguish reads, writes, or execution. No controlled startup override or UI comparison was performed.

## Interpretation limits

- Empty help remains unresolved, and an upstream UE default does not prove version alignment.
- Registry membership and local binary references do not prove `.ini` override acceptance, player-facing editability, or behavior in the current build.
