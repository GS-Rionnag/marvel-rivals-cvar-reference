# Niagara CVar batch E: emitter bounds, LOD, and GPU debug

This page documents the next 25 uncovered `fx.Niagara.*` variable rows from the community registry. Registry help and captured snapshot values are the starting evidence; the snapshot build and capture method are unknown, so values below are observations rather than confirmed defaults. Build scan counts refer to read-like instructions matched to a registered `ref_rva` in Marvel Rivals Shipping build `1.1.4042190`. They are static access candidates, not complete call-path traces.

## Evidence and override limits

All 25 names are registered as `ref` entries in the supplied community attachment. The table's descriptions and values come from that registry and its companion snapshot; the snapshot's build and collection method are unknown. Read-like address matches show that instructions access a CVar value in the scanned Shipping executable, but do not show that a particular branch runs in a match or that a startup `.ini` override changes that value. The 25 entries include 14 with at least one read-like candidate; the remaining 11 had only address-taking references or no value-read candidate in this scan.

No controlled `.ini` override, live console query, or in-game visual/performance comparison was performed for this batch.
