# LumenScene CVar batch E

This guide records the final 25 registered `r.LumenScene.*` variable names that were uncovered after batches A–D in the latest public documentation inventory. Adding these rows closes the currently known `r.LumenScene.*` family among the supplied community registry’s `var`/`ref` names. That registry has 8,973 unique variables/references overall and does not prove it contains every engine/game CVar. The registry capture build and method are unspecified. Snapshot values come from `CVarDump.txt`; Epic UE 5.9 defaults and descriptions are exact-name upstream references only, not verified Marvel Rivals defaults.

Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates may be reads, writes, comparisons, or initialization; address-taking matches show address use only. Counts do not establish a complete function path or execution. No controlled startup override or in-game render test was performed.

## Interpretation limits

- Community and Epic descriptions explain intended surface-cache operations such as card capture margin/refresh, compression, feedback, page sizes, freeze/logging, and mesh-card behavior. They do not verify the code path or effect of any value in Marvel Rivals.
- The visible `var`/`ref` category is evidence from the supplied dump, not proof that a startup `.ini` override is accepted. Static references alone do not prove in-match use.
- Captured snapshot values are observations, not defaults or recommendations. Where the catalog marks an Epic default but its description cell is a literal `.`, the default value is retained and the empty description is omitted.
