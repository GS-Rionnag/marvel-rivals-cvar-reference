## Evidence and editability limits

- All 17 exact names have one row each in `console_vars.tsv` and in the generated community registry catalog. Types and help above come from that registry; the captured values come from `CVarDump.txt`. The registry's source build and the snapshot capture procedure are unknown, so snapshot values are observations rather than proven defaults or recommendations.
- The target used for the local static scan is Marvel Rivals Shipping build `1.1.4042190`. For `ref` entries, the saved address scan records RIP-relative candidate instructions against the registered reference address. A load, comparison, or arithmetic instruction supports that the value is accessed at that site; it does not prove the branch runs during a match or that an override reaches it. Entries described as “address-taking/setup only” have no direct value-read candidate in this scan. Three `var` entries do not expose a `ref_rva` in the registry, so the scanner cannot use the same direct-reference method for them.
- `p.Chaos.TriMeshPerPolySupport` is the only entry here whose help explicitly says a runtime change will not work. A config line can express a typed value for any of these names, but registry presence and static code references alone do not prove that the game's startup loader accepts or preserves it. No controlled runtime override was tested.
- No direct Chinese-help translation entry was found for these 17 names.
