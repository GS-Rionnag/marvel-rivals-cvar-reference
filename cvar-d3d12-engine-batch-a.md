## Interpretation limits

- Captured snapshot values are not defaults or recommendations.
- Epic UE 5.9 descriptions are upstream context and do not prove the same engine version or active path in Marvel Rivals.
- The community registry does not identify its game build or establish that every name accepts a startup `.ini` override.
- Static references are leads; function-level and runtime behavior remain unverified.
