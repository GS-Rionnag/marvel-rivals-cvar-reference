# AbilitySystem CVar batch A

This page covers 25 AbilitySystem settings from the preserved community `var`/`ref` registry. The registry attachment does not identify its game build or capture process. `CVarDump.txt` values below are observed snapshot values, not verified defaults. Local binary evidence refers to Marvel Rivals Shipping build `1.1.4042190` and the saved x64 address-reference scan. The scan's direct-memory candidates include both reads and writes; a matched instruction alone does not prove that a setting takes effect during a normal match.

## Registry, snapshot, and local-code scope

- All 25 exact names have rows in the preserved [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322); values are from [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452). The snapshot does not identify its build, collection method, or whether values were user-overridden.
- Build-specific instruction candidates come from [`build-4042190-cvar-address-hits.tsv`](EVIDENCE.md#evidence-artifacts-not-included). For `ref_rva` entries, comparisons or scalar loads support value-read candidates. The entries marked setup-only have `ref_rva=0` or no direct instruction candidate; `obj_rva` setup writes/address-taking are not runtime reads.
- Nearby strings for all candidates are indexed in [`cvar-game-build-4042190-context.md`](EVIDENCE.md#build-specific-static-analysis), but neighboring text may be unrelated. The `GameplayCue.DisplayDuration` help/context mismatch remains unresolved.
- Chinese help translations are collected in [`cvar-chinese-help-translations.md`](cvar-chinese-help-translations.md) and remain unreviewed. Do not treat those renderings as authoritative source code comments.
- The supplied loader syntax can express these names as startup overrides. No evidence here verifies that Marvel Rivals accepts any particular override, that it survives later initialization, or that a visual/gameplay result follows.
