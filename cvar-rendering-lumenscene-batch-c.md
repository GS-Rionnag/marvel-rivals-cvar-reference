## Interpretation limits

- The names and help describe surface-cache mesh-card instance merging and size/resolution parameters. They do not reveal the full merge eligibility rules, geometry consequences, asset coverage, or rendering result in this game build.
- Exact UE 5.9 matches are upstream context only. Snapshot values are observations from the supplied dump and are not recommendations or confirmed defaults.
- Some source help is terse. Chinese translations are explicitly marked unreviewed. Build address counts are leads, not code-path or runtime proof.
- Registration plus a static reference does not prove `.ini` editability or that a player can change the value in Marvel Rivals.
- Duplicate-record audit: 0 of these 18 names have conflicting kind/type/help rows in the source; repeats were not treated as separate CVars.
