# Chaos game-specific controls, batch D

This page documents 25 `p.Chaos.*` entries from the preserved `var`/`ref` registry. They cover Geometry Collection dirty-state and effects, particle/animation limits, broadphase and collision-task scheduling, navigation update parameters, and diagnostic names. Registry values copied from `CVarDump.txt` are captured values, not verified defaults. The attachment does not identify the game build or capture method.

## Registration, upstream, and editability limits

- All 25 exact names have `ref` rows in the preserved [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322). Twenty-four have captured values in [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452); the FString `p.Chaos.GcOwnerName` is absent. The dump's capture build and whether any value is a default remain unknown.
- Only `p.Chaos.MaxInflationScale` and `p.Chaos.MinEvolution.ForceMaxConstraintIterations` have exact Epic 5.9 reference matches in the generated community catalog. Those upstream descriptions are useful context, not proof of fork parity. The other entries appear game/fork-specific in this source set.
- The instruction locations come from [`build-4042190-cvar-address-hits.tsv`](EVIDENCE.md#evidence-artifacts-not-included), matched against registry RVAs for Marvel Rivals Shipping build `1.1.4042190`. The scan's `direct-memory-candidate` entries are disassembly-level loads/comparisons; it does not establish a full caller/control-flow path, that the path executes in a match, or that the game accepts a startup override.
- `p.Chaos.MidPhaseAssignBatchSizee` and `p.Chaos.MidPhaseProcessBatchMinSize` are related by help/name and nearby code locations, but the precise division between assignment and processing roles is not established. The separate [midphase redistribution guide](cvar-chaos-midphase-redistribution.md) documents other settings and should not be treated as proof that these three act as a single control group.
- The loader syntax described in [CVar override research](cvar-overrides.md) can express a `name=value` line, but none of these entries has a controlled startup-override test here. Snapshot values are not recommendations.
