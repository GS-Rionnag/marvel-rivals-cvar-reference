# Lumen hardware ray tracing and irradiance-field CVars: batch B

This guide covers 25 exact `r.Lumen.*` entries from the community registry. It compares their captured values with exact-name matches in Epic's UE 5.9 CVar reference and records the saved address scan for Marvel Rivals Shipping build `1.1.4042190`. The Discord attachments do not identify their capture build. Epic defaults are upstream context, not a claim about Marvel's default or behavior.

## What this says about changing them

The first six variables, plus `r.Lumen.LightingDataFormat`, `r.Lumen.MarvelStyleAmbientDivExposure`, and `r.Lumen.ProbeHierarchy.SamplePerPixel`, are `var` rows whose saved hits address `obj_rva` setup storage; those hits are not proof that renderer code reads an override. The other sixteen entries have direct `ref_rva` memory candidates in the saved scan, including scalar loads or comparisons shown above. These support local build-specific code use, but do not show that the loader's value reached that code, that the path executes in a normal match, or that a change is visible.

Under the user's `[Overrides]` syntax, each row can be written as `name=value`; this establishes only that the loader syntax can express a line. No runtime dump, config-acceptance check, or controlled in-game comparison was made. The snapshot values match the upstream UE 5.9 reference defaults for the 23 names that have exact matches, but the attachment build is unknown and these values are not confirmed Marvel Rivals defaults. Do not treat that coincidence as proof of live values or settable status.
