# Virtual Texturing CVar batch B

This guide covers the next 25 alphabetically sorted currently undocumented `r.VT.*` registered variables after batch A. Community help gives intended controls; captured values and exact-name Epic UE 5.9 matches are separate evidence, not proof of the active game path.

Build reference evidence comes from static analysis of Marvel Rivals Shipping build `1.1.4042190`. Direct-memory candidates do not distinguish reads, writes, comparisons, or initialization; object-address references do not prove value use. No controlled startup override or visual test was performed.

## Interpretation limits

- Help may describe editor, platform, or renderer paths that are not active in the game build.
- Snapshot values are not defaults; absent UE references remain unknown.
- Registry presence and address evidence do not establish `.ini` acceptance or player-facing editability.
