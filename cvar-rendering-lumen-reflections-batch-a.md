# Lumen Reflections CVar batch A

This page documents the next 25 uncovered `r.Lumen.*` registry names. They are all under `r.Lumen.Reflections.*` and cover hierarchical screen traces, reflection-ray limits, radiance-cache reuse, SceneColor fallback sampling, and screen-space reconstruction.

The `Dump snapshot` values come from the community `CVarDump.txt` attachment; its game build and capture method are unknown. `UE 5.9 default` is an exact-name upstream reference match where available, not proof that Marvel Rivals uses that exact engine version or default. The installed build scan is static evidence from Shipping build `1.1.4042190`; direct-memory candidates indicate instructions accessing a stored CVar value, not a complete code path or a live effect.

## What this establishes about editability

The community registry classifies 21 names as `ref` and four as `var`. The build scan found direct value-access candidates for 20 names. Five rows have no matching `ref_rva` read candidate: the four `var` entries plus `r.Lumen.Reflections.SupportViewport`. These are static observations for one executable build. They do not prove that a startup `.ini` override is accepted, survives later config layers, or changes a live match. A value-access candidate also does not show that the corresponding Lumen reflection path is enabled on a particular system.

The snapshot differs from the UE 5.9 default for `MaxRoughnessToTrace`, `MaxRoughnessToTraceForFoliage`, `RadianceCache`, and `ScreenSpaceReconstruction.TonemapStrength`. The `SupportViewport` row has only a short additional object-table label, while `RoughnessFadeLength` has no help text. Keep those evidence gaps visible; do not treat snapshot values as recommendations or verified Marvel Rivals defaults. No controlled `.ini` comparison, live console query, renderer-capability check, or in-game image comparison was performed for this batch.
