Several exact names occur repeatedly in the attachment because it records multiple object registrations; repeated rows are not counted as distinct CVars. For example, `GAS.Projectile.BounceWaitReentryGuard` has 27 same-metadata rows and `GAS.Projectile.CreateFakeAdvancedKey` has 382. Those duplicate rows agree on kind, type, and help; their object RVAs differ.

The table separates the captured snapshot from exact-name Epic UE 5.9 reference defaults. The registry attachment does not identify its build or capture method. Community help and translations describe intended controls, not proof that they affect a live match. The saved binary scan shows candidate references only; it does not establish startup-override acceptance or an executed gameplay path.

## What the evidence supports

- The four `104711`–`104720` names have Chinese community help translated as Jeff ability toggles. These translations are unreviewed, and neither their exact meaning nor effect in this game build has been verified.
- `GAS.Projectile.2212.10223111.DebugBounceDamage` and `.DebugReturnVisual` are described as diagnostics with `0`/`1` toggles. That is supplied help, not confirmation of where their output goes or whether the relevant code executes.
- `GAS.Projectile.MaxClientPerChar` and `.MaxServerPerChar` have help defining a projectile-count limit per `(Instigator, ProjId)` on the named side, with `0` described as unlimited. The help does not establish where those limits are enforced in Marvel Rivals.
- `GAS.Projectile.ForceMove` help describes whether bounce/penetrate movement forces server location. The direction of reconciliation and its gameplay effect were not traced.
- `GAS.Projectile.SkipMassRegisterAllActorTickFunctions` help says it skips `RegisterAllActorTickFunctions(true, true)` for Mass projectile actors and that `0` restores registration. This remains a registry description until the relevant game path is traced.
- For `ref` rows, the scan includes `ref_rva` direct-memory candidates, but they may be reads, comparisons, or writes. For `var` rows, the supplied rows have no `ref_rva`; scanned `obj_rva` matches concern object addresses and do not demonstrate CVar value consumption.
- A `var`/`ref` registry kind and a captured value do not prove the game accepts a player `.ini` override. No controlled config launch or in-match behavior comparison was performed.
