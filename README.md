# Marvel Rivals CVar Reference

A documentation-only reference to Marvel Rivals console variables: community descriptions and snapshots, upstream Unreal Engine meanings, and carefully scoped build-specific static-analysis findings. It does not include game files, mods, local configs, raw dump files, scripts, or personal computer data.

## Reading the guides

A registered name, a captured value, and a documented Unreal meaning do not prove that a Marvel Rivals startup override is accepted or changes gameplay. Each guide separates those evidence types and marks unknowns. Snapshot values are observations, not defaults or recommendations.

See [Evidence, sources, and scope](EVIDENCE.md) for source links and limitations.
