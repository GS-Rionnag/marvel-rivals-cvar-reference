# Game-specific CVar descriptions from embedded text

This guide isolates registered game-specific CVars whose nearby binary text was previously interpreted as useful help. The list was seeded by the [community config post](https://discord.com/channels/1452445537298022637/1556428197820633269); the explanations below come from static text in Marvel Rivals Shipping build `1.1.4042190`, not from that post. Text proximity does not prove a CVar-to-string association, and the short readings remain analyst interpretations until confirmed by code references or runtime queries.

The table contains only CVar names in the community `var`/`ref` registry. Community help, Epic UE 5.9 defaults, the captured snapshot, and embedded-text interpretations are shown as separate evidence. Registry alignment and the capture build of the community dump remain unverified. Direct-address matches can be reads, comparisons, writes, or setup; no in-game override test was run.

## Using these entries

- The embedded text can point to useful behavior but it is not confirmed help text unless a typed reference or live query ties it to the CVar.
- Some descriptions involve networking, gameplay, simulation, asset residency, or audio. They are not graphics presets and may change gameplay behavior.
- Snapshot values are captured values, not recommendations. Epic defaults apply only as upstream reference data, not as confirmed Marvel Rivals defaults.
