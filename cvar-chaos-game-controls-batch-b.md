# Chaos game-specific controls, batch B

This page documents 25 additional `p.Chaos.*` registry entries covering Geometry Collection events, rendering/debug controls, and particle lifecycle behavior. Exact names, types, and help are from the preserved community registry; values are from `CVarDump.txt` when present. The registry attachment does not identify its capture build or method, so snapshot values are not verified defaults.

Local code evidence refers to the saved RIP-relative address scan of Marvel Rivals Shipping build `1.1.4042190`. A direct `ref_rva` memory candidate means the instruction references the variable's storage; it supports local read/use evidence but does not by itself establish surrounding behavior or that the path runs in a normal match. No runtime override tests were performed. None of these names has an entry in the saved Chinese-help translation guide.

## Evidence and limits

- Exact names, `var`/`ref` kinds, types, descriptions, and reference RVAs: [`console_vars.tsv`](https://discord.com/channels/1512820805615091712/1512825591529869383/1570970983353950322). Captured values: [`CVarDump.txt`](https://discord.com/channels/1512820805615091712/1512825591529869383/1562934699502866452). The value capture is not a defaults list.
- Local references: [`build-4042190-cvar-address-hits.tsv`](EVIDENCE.md#evidence-artifacts-not-included). The listed candidate instructions directly reference each nonzero `ref_rva`; compare/load operations are evidence of access, not full behavioral reconstruction.
- The help strings were not independently translated or repaired. The four entries with blank help and the vague/misaligned descriptions are marked as unresolved rather than inferred from their names.
- Per the supplied loader example, a named value can be placed under `[Overrides]`; this page does not establish whether the game accepts it, applies it after startup, or changes rendering/gameplay. See [CVar override evidence levels](cvar-overrides.md#does-a-cvar-actually-change-in-marvel-rivals).
