# Network CVar batch K: remaining entries

This page documents the six remaining uncovered `Net.*` variables in the supplied community registry. Registry help and captured values are preserved as supplied; the snapshot's game build and collection method are unknown, so captured values are observations rather than verified defaults. The local static scan targets Marvel Rivals build `1.1.4042190`. Direct access to a `ref_rva` shows that code touches the CVar value in this build, but does not by itself prove the branch executes in a match or that startup configuration can change it.

## What can be said about overrides

The community attachment records these names as `var` or `ref`, and the build contains their names. Two settings have stronger game-specific consumer evidence: the traffic-control variables have previously inspected value reads, and `Net.UsePackedShadowBuffers` has one direct comparison candidate. The three `var` entries have no registry `ref_rva`; their object-address setup matches do not prove that code reads their current values. None of these facts establishes that the user's startup `.ini` accepts a line, that an override wins in the running game, or that the effect is client-controlled. In particular, shared-replication code may act on server-owned state. No controlled override or live network test was performed for this batch.
