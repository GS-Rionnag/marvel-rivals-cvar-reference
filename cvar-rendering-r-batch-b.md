# General `r.*` CVar batch B: compute, custom depth, and D3D

This guide documents the next 25 alphabetically sorted uncovered registered names with the exact `r.` first component, after batch A and all other local/public explanatory tables. The entries cover compute-graph compilation, contact shadows, shader/material configuration, culling, custom depth/mask passes, D3D11 diagnostics, and D3D12 async compute/payload controls.

Community `var`/`ref` classifications are registry metadata. Captured snapshot values are not assumed to be defaults. Epic UE 5.9 descriptions/defaults are upstream references and do not establish that Marvel Rivals uses the same code path.

Static address-reference evidence comes from Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` counts are kept separate from `address-taken` references; they do not identify a read/write direction or establish execution. No config override or in-game effect was tested.

## Source differences and limits

- `r.D3D12.AllowAsyncCompute` has a snapshot of 0 while the exact Epic UE 5.9 reference default is 1.
- `r.ContactShadows.NonShadowCastingIntensity` is described as deprecated by the supplied help, which directs users to Light Component parameters. This is source documentation, not proof of use in the game.
- `r.CustomUnsafeZones` is an FString; its supplied help specifies a portrait/landscape zone string format, but the dump has no captured value and the Epic reference contains no concrete default.
- Several entries are editor-, cook-, platform-, or debug-specific according to their help. Those qualifiers should not be generalized into a game-client effect.
- Static references and registry kinds do not prove startup override acceptance. No override was tested.
