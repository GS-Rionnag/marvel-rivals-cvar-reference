# Animation system CVar batch D

This page documents the next 25 uncovered `a.*` entries in the supplied community registry. Registry help gives useful descriptions for several animation controls, but it does not provide every implementation detail. Values from the companion snapshot are observations from an attachment with unknown build and collection method, not verified game defaults or recommendations.

The local address scan targets Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate against `ref_rva` means an instruction refers to the stored CVar value; it does not reconstruct the full control flow or prove that a startup `.ini` override is honored. `var` rows and entries without a `ref_rva` can have object/setup matches without a confirmed read of the current value.

## Editability and evidence limits

All 25 names appear as `var` or `ref` entries in the community registry. For `ref` entries with direct-memory candidates, static instructions access the registered value address in build `1.1.4042190`; the scan still does not demonstrate that the loader accepts an override, that a value survives later config layers, or that a client setting has authority over server behavior. For `var` entries and zero-reference rows, setup/object matches are not evidence that the stored value is read.

Snapshot values are not canonical defaults. No controlled startup-config comparison or in-game animation, camera, movement, or debug-draw test was performed for this batch.
