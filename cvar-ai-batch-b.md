It covers ability-use logging, game-specific AI state/flow switches, crowd diagnostics, and replication/visualization LOD controls.

Community `var`/`ref` rows, captured snapshot values, and exact-name Epic UE 5.9 references are separate evidence types. None establishes that Marvel Rivals accepts a config override or changes runtime behavior. Static build findings below are from address-reference scanning of Shipping build `1.1.4042190`; direct-memory candidates are not classified as reads, writes, or executed paths.

## Interpretation and translation limits

- Crowd `DrawDebug*` entries with supplied help explicitly depend on `ai.crowd.DebugSelectedActors`; their descriptions do not prove debug drawing is visible in the shipped game.
- `ai.FlightFormation.DebugDraw` has Chinese source help and an assistant English rendering. The rendering is unreviewed; it is included only to make the supplied description discoverable, not as independently verified behavior.
- `ai.NavCollisionAvailable` describes whether NavCollision is cooked and available. It should not be read as a verified switch for a running client.
- `ai.MassAIWantPlayerState` has no snapshot value in the supplied dump. Missing data is left missing, not treated as `false`.
- Registry entries and static references do not prove a startup `.ini` override is accepted or that an AI behavior changes. No game runtime or controlled override test was performed.
