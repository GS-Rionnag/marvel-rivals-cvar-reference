# Mass CVar batch A

This guide covers the first 25 alphabetically sorted currently undocumented distinct `mass.*` registered `var`/`ref` names. Descriptions are limited to supplied community help and exact-name Epic UE 5.9 reference help where present. Empty or placeholder descriptions are left unresolved; names alone do not establish behavior.

The snapshot is a captured value, not a default. Epic 5.9 defaults are upstream references. Static address candidates are from Marvel Rivals Shipping build `1.1.4042190`; direct-memory candidates do not distinguish reads, writes, comparisons, or initialization. No controlled startup override or in-game comparison was performed.

## Interpretation limits

- Community help describes intended behavior, not proof that the control is consumed by the game’s live Mass path.
- A `var`/`ref` registry row and binary address match do not establish player-facing editability or startup `.ini` acceptance.
- Static address candidates are not runtime execution counts. No effect, performance change, or match behavior is claimed.
- Conflicting repeated registry metadata: 0; duplicate rows are not separate CVar names.
