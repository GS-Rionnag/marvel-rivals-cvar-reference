## Evidence limits

- Snapshot values are observations from `CVarDump.txt`, not verified game defaults or recommendations.
- No exact UE 5.9 default was recorded for these no-dot entries in the generated community-catalog comparison. This does not identify the game’s engine version.
- English renderings for the Chinese descriptions are assistant translations marked unreviewed in the preserved translation table. The source help for `ShowServerCollision` is empty; its name alone is not a definition.
- Address-scan counts refer to candidate instructions referencing registry `ref_rva`/`obj_rva` fields. They are not control-flow-validated reads/writes or proof of registration. The separate executable name inventory only searches dotted names.
- No controlled runtime test established whether these entries are accepted through the loader’s `[Overrides]` section or what changes in-game.
