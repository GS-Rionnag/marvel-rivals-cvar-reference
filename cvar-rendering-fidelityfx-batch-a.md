It records community help, captured values from `CVarDump.txt`, and exact-name Epic UE 5.9 reference defaults separately. The community attachments do not state the game build or capture process.

Address-taking references are separate and do not establish runtime value use. No function body or execution path was traced. No startup override or in-game comparison was performed.

## Interpretation limits

- These names span FidelityFX Frame Interpolation (`FI`), FSR support/version controls, and early FSR3 setup options. Supplied help describes intended function, but does not prove a feature is activated in Marvel Rivals or on the current hardware/backend.
- Exact-name Epic UE 5.9 entries are upstream context only. They do not prove the game uses that engine implementation. Snapshot values are captured observations, not verified effective defaults or recommendations.
- Address-reference candidates do not establish live behavior, accepted `.ini` overrides, visual quality, or performance changes. The `var`/`ref` registry category is not an editability guarantee.
- Duplicate-record audit: 0 selected name(s) have conflicting kind/type/help metadata across repeated registry rows. Snapshot cross-check against the attached dump: 0 mismatches.
