## Interpretation and limits

- Where supplied help describes experimental compute materials, spline meshes, tessellation, coarse mesh streaming, culling, or CustomDepth, it describes the CVar author’s stated purpose. It does not prove the named feature is enabled, reachable, or supported by this game build.
- The `var` and `ref` labels come from the community dump. Registration and a binary address reference do not prove that an `.ini` startup override is accepted or that the value changes rendered output.
- An empty help field stays unresolved; the name or presence of a matching Epic default is not used as a substitute definition.
- A difference between captured snapshot and Epic 5.9 default is a provenance difference, not evidence that a value was changed intentionally.
