# Animation-system CVar batch F

This page covers the next 25 uncovered `a.*` entries in the supplied community registry. They span hit-shape updates, movement input, server animation ticking, Montage notifications, KawaiiPhysics, animation sharing, and skin-weight profiles. Registry help is summarized below; the companion snapshot has an unknown build and collection method, so its values are observations rather than verified defaults.

The local address scan targets Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate against `ref_rva` shows an instruction accessing the registered value address, but does not recover the full branch or establish that a startup `.ini` override is accepted. `var` rows and reference rows without a direct-memory candidate are not treated as verified reads.

## Override and evidence limits

The `ref` rows with direct-memory candidates show that instructions in build `1.1.4042190` access the stored CVar value. They do not show that the path runs in a live match, that a local startup `.ini` can change the value, or that a client setting controls a server-owned path. The six `var` entries do not have matched direct value reads in the saved scan. No controlled override or in-game animation/movement test was performed for this batch.

Snapshot values are not canonical defaults. `a.Montage.TriggerAnimNotifyBySettingWhenRedirecting` is captured as `true` while its help says the default is `false`; that discrepancy is unresolved. The Chinese translation for `a.SelectTarget.ResetTargetFromEvent` is unreviewed.
