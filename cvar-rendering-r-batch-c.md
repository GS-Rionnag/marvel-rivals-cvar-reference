# General `r.*` CVar batch C: D3D12 and distance fields

This guide documents the next 25 alphabetically sorted uncovered registered names with exact first component `r.`, after batches A and B plus all local/public explanatory tables. Most entries concern D3D12 diagnostics and ray-tracing controls; the batch also includes DBuffer decals and distance-field shadow scaling.

Community `var`/`ref` is registry metadata. Captured snapshot values are observations, not defaults or recommendations. Exact-name Epic UE 5.9 references are upstream evidence and do not prove Marvel Rivals uses the same path or accepts a config override.

The address scan covers Marvel Rivals Shipping build `1.1.4042190`. `direct-memory-candidate` counts and `address-taken` counts are reported separately. Candidate matches are not directionally interpreted and do not prove runtime execution.

## Source differences and interpretation limits

- `r.D3D12.BreadCrumbs` has a captured snapshot of 0 and an Epic UE 5.9 reference default of 1.
- `r.D3D12.NvAfterMath` also has a captured value of 0 versus an Epic reference default of 1. The supplied help says its crash-dump feature applies only to NVIDIA hardware.
- `r.D3D12.SkipRedundantAdapterProbes` has no captured snapshot or exact Epic default in this catalog; its help distinguishes Shipping from Development/Test.
- `r.D3D12.RayTracing.DebugForceBuildMode` is described as not runtime-tweakable. This statement comes from the supplied upstream help and does not establish how the game is configured.
- Debug layers, GPU crash diagnostics, and ray-tracing settings are documented here as intended engine controls. There was no override or in-game test.
