## Interpretation limits

- The labels describe intended pipeline controls such as visibility, rasterization, base-pass building, budget limits, diagnostic events, and streaming. They do not show which backend/path is active in Marvel Rivals.
- Empty community help remains unresolved unless an exact upstream description exists; an upstream description is kept visibly labeled and does not itself prove the game uses that behavior.
- `r.Nanite.StatsFilter` has no value in the supplied snapshot; `—` means unavailable in this capture, not zero.
- `var`/`ref` registry kind, snapshot values, and static reference matches do not prove startup-config acceptance or an in-game effect. Snapshot values are not recommendations.
