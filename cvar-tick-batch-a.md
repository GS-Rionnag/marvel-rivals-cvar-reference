# Tick CVar batch A: async tick and dispatch controls

This guide covers the first 25 currently uncovered exact lowercase `tick.*` registered names after checking explanatory CVar tables in the local docs and public reference repository. Names are deduplicated across registry rows. Three additional uncovered `tick.*` names remain after this batch.

Community `var`/`ref` help records the source author’s stated purpose; it does not confirm current Marvel Rivals runtime behavior. Snapshot values come from the supplied `CVarDump.txt`; Epic UE 5.9 defaults/descriptions are exact-name upstream references, not confirmed game-build defaults. Static address candidates come from Shipping build `1.1.4042190`. Direct-memory candidates can be reads, writes, comparisons, or initialization; address-taking matches alone do not establish a value read. No runtime or startup override was tested.

## Interpretation limits

- Registry membership and snapshot presence do not establish startup `.ini` acceptance, player editability, or a live game effect.
- Epic references are upstream exact-name matches; version alignment with the game build is unconfirmed.
- Static address matches are not complete value-use traces. Missing scan hits do not prove a CVar is unused.
