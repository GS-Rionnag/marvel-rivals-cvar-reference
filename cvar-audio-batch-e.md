# Audio CVar batch E

This guide documents the 12 remaining uncovered distinct registered `au.*` entries in the supplied community registry. The family includes ADPCM seek behavior, compression, DSP FFT selection, editor/cooking options, non-real-time rendering, Resonance quality, submix validation, VOIP prioritization, and Vorbis failure handling. Descriptions are sourced from community help and exact-name Epic UE 5.9 reference help where available; neither is proof that Marvel Rivals uses the same runtime path.

Snapshot values are captured observations. Epic UE 5.9 defaults are upstream references only. Static address candidates below are from Marvel Rivals Shipping build `1.1.4042190`; direct-memory candidates may be reads, writes, comparisons, or initialization, while address-taking only shows a reference. No controlled startup override or in-game audio test was performed.

## Interpretation limits

- Community and Epic help describe intended engine behavior; this guide does not prove those paths are active in the game build.
- Snapshot values are not defaults or recommendations. A missing exact-name Epic match is not evidence that the game lacks a default.
- Registration and static address evidence do not prove that a player can set the CVar through the startup `.ini`, that an override wins at launch, or that it changes live audio.
- Conflicting repeated registry metadata found: 0; repeated rows were not counted as separate CVar names.
