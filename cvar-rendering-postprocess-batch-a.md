# Rendering post-processing CVar batch A

This guide covers 25 previously undocumented `r.PostProcess*` and `r.PostProcessing*` variables in the supplied community registry. The registry's build and capture method are unknown. Snapshot values are observations, not verified Marvel Rivals defaults or recommendations. Where the registry has an exact Unreal Engine 5.9 reference match, that is upstream context only and does not prove the game uses identical code.

## What this says about editability

All 25 rows are `var` registrations with `ref_rva=0` in the community attachment. The build scan finds the embedded names and object-address setup references, but these are weaker than a direct read of the CVar's current value; registration setup does not establish that the runtime feature consumes a startup override. Several entries are rendering/material controls, but the available evidence does not show that a given renderer, SMAA mode, post-process material, broadcast alpha path, or outline pass is active in a particular match.

No controlled `.ini` override or in-game visual comparison was performed for this batch. Snapshot values do not establish defaults. In particular, `PropagateAlpha` and `SMAAStencil` differ from the defaults stated by their help, demonstrating why snapshot values should not be copied as recommended settings.
