# Ability input delay

| Exact name | Registry type | Supplied meaning |
| --- | --- | --- |
| `predict.delayinput` | `float` variable | The registry describes a delay between input on the autonomous client and delivery to the ability system component. |

The source gives no units or timing semantics. Startup override support and runtime effects in Marvel Rivals remain unverified.
