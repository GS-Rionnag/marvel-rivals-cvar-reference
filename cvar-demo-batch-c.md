## Interpretation limits

- Several entries have no explanatory help in either source; those rows remain unresolved rather than receiving a name-based definition. `demo.DeathReplayTaskTimeout` is typed as float, while its supplied help says “if true” without stating a numeric threshold or units; precise value semantics remain unclear.
- Chinese community help is preserved with an English assistant translation marked unreviewed where one is available. Translation is not independent confirmation.
- The values are snapshots, not recommendations. Registered `var`/`ref` rows and static address candidates do not prove that a specific replay path uses the setting or that a mod loader honors it.
