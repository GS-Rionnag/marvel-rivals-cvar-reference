# Lumen Translucency Volume and reflections CVar batch A

This guide documents the 16 remaining uncovered `r.Lumen.TranslucencyVolume.*` entries and all 8 currently registered `r.Lumen.TranslucencyReflections.*` entries. Community help, exact-name Epic UE 5.9 references, and captured snapshot values are separated. The dump has no verified game build/capture method; an upstream match does not establish the game’s engine revision or runtime behavior.

Build evidence is static address-reference scanning for Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate can represent a read, comparison, or write. Object references for `var` entries can be registration/setup. No match path was traced, and no live override or rendering test was performed.

## Interpretation limits

- The Translucency Volume rows cover remaining radiance-cache atlas/resampling controls, temporal reprojection, spatial filtering, trace origin/mode, distance-step controls, visualization, and voxel tracing. The supplied help identifies intended roles where present; settings without help remain explicitly unresolved.
- The reflection rows describe radiance-cache use, reflection marking/downsampling, front-layer depth rejection, and resolution controls where the sources provide descriptions. They do not establish which reflection path the game selects.
- Snapshot values are captured values, not recommendations. Epic 5.9 defaults appear separately; `—` means no exact default entry was found in the community registry.
- Neither static address references nor CVar registration prove an override is accepted by this mod loader or changes a live match.
