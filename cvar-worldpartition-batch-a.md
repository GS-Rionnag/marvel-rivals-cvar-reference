# World Partition `wp.*` CVar batch A

This guide records the first 25 currently uncovered registered names whose exact first component is `wp`. They cover slow-streaming thresholds, content-bundle diagnostics, server-streaming toggles, runtime spatial-hash behavior, HLOD cull-distance processing, and HLOD/virtual-texture warmup.

The community registry’s `ref`/`var` kind is registration evidence, not proof that a config override is accepted or changes the game. Snapshot values are captured observations; Epic UE 5.9 defaults and help are upstream reference data. Marvel Rivals runtime use is not established by a name or upstream match.

Static scan evidence comes from the address-reference inventory for Marvel Rivals Shipping build `1.1.4042190`. The scan’s `direct-memory-candidate` class is kept separate from `address-taken`. Candidate hits may be reads, writes, comparisons, or initialization; none is a runtime trace.

## Interpretation limits

- The streaming and HLOD descriptions come from registry help or exact UE 5.9 matches. They do not prove the game uses the corresponding World Partition systems or code paths.
- `wp.Runtime.EnableServerStreaming` and `wp.Runtime.EnableServerStreamingOut` are described as startup-sensitive settings, but this does not verify that Marvel Rivals supports them in its startup configuration.
- HLOD warmup help says Nanite and virtual-texture warmup require `wp.Runtime.HLOD.WarmupEnabled` to be 1. This documents the supplied engine help, not an observed game configuration.
- Snapshot values are not recommendations. Static address matches do not demonstrate an in-game effect or safe override.
