# Lumen miscellaneous and visualization CVar batch A

This guide documents the 19 remaining uncovered registered `r.Lumen.*` CVars in the supplied community registry. It covers Lumen scene visualization, software tracing against Mesh SDFs, global support/scalability switches, and related rendering controls. Community help, Epic UE 5.9 descriptions, and captured values remain separate because some descriptions or mode lists differ. The registry does not establish the game build or capture method.

Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate may be a read, comparison, or write; `var` object-address references can be setup code. Counts below do not establish runtime consumption or that an override is accepted. No instruction-level path trace or in-game test was performed.

## Interpretation limits

- `r.Lumen.Visualize` has different mode text in the community help and Epic 5.9 reference. The table preserves each source separately; the difference is not resolved as a game-version change.
- Rows marked `—` have no help/description in that source. Where both are blank, exact behavior remains unresolved rather than inferred from the CVar name.
- Snapshot values are captured values, not defaults or recommendations. Epic 5.9 defaults are upstream context and do not prove Marvel Rivals uses those defaults.
- Presence in a community registry or static address scan does not prove that a retail match uses the code or that this mod loader can override the value.

For the broader Lumen set, see the [Lumen guides in the documentation index](README.md) and [community CVar registry](cvar-community-registry.md). Build-scan methodology is documented in [build-specific static-analysis notes](EVIDENCE.md#build-specific-static-analysis).
