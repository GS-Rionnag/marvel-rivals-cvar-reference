# Slate CVar batch B: UI processing, blur, and invalidation

This batch documents the first 25 alphabetically sorted currently uncovered registered `Slate.*` entries after checking all public UI and Slate explanatory guides. It includes widget processing and background blur, UI contrast, VR rendering, event/draw diagnostics, fast/global invalidation options, invalidation-list sizing, and letterboxing.

The community registry’s `var` or `ref` kind describes the supplied registration table; it does not prove an override is accepted by Marvel Rivals. Snapshot values are read from the supplied `CVarDump.txt`; Epic UE 5.9 values are separate exact-name upstream references. Neither is asserted to be the game’s effective default.

Build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. The literal `direct-memory-candidate` class may mean a read, write, comparison, or initialization. It is reported separately from `address-taken` references. These counts are not a runtime trace.

## Source differences and unknowns

- `Slate.EnableDrawEvents` has a captured snapshot of 0 and an Epic 5.9 reference default of 1, but the supplied help is empty and the additional object-help field is only a period. Its exact behavior is not described by those sources.
- `Slate.EnableGlobalInvalidation` has a captured snapshot of `true` and an Epic 5.9 reference default of `false`; the registry provides no explanatory help, so the effective game behavior remains unknown.
- Several entries have an upstream default but no descriptive help. Those are left unresolved rather than defined from their names.
- A static reference or registered kind does not prove the game honors a startup override or that the setting affects Marvel Rivals UI. No override or visual test was performed.
