This guide covers 25 exact `r.Shadow.*` names from the community registry. It separates the registry's help and captured values from what the installed Marvel Rivals Shipping binary shows. A captured value is not a default.

## What the local binary scan establishes

The installed `Marvel Rivals Shipping executable` is build `1.1.4042190` (SHA-256 `omitted from this documentation-only project`). In the saved RIP-relative scan, the three `ref` entries above have direct value-use candidates: one zero comparison for `CachedShadowsCastFromMovablePrimitives`, three comparisons for `CacheWholeSceneShadows`, and one byte load for `OnlyOneShadowMapPerCharacter`. The other 22 `var` entries have no direct `ref_rva` value-read candidate; matches to `obj_rva` include address-taking and memory writes, which are not proof that gameplay reads their values. Indirect reads, accesses outside the scanned executable, and settings applied through a different representation can be missed.

Community `kind=var` / `kind=ref` rows describe the attachment's registry schema, whose build and capture procedure are unknown. They do not prove that all 25 names are registered in the installed build or accept a particular loader source. The saved binary evidence is static; no override was applied in game and no controlled visual or performance A/B test was performed. A line under `[Overrides]` is expressible with the provided loader syntax, but that alone does not prove game acceptance or a behavior change. Use the editability evidence model in [CVar overrides](cvar-overrides.md) before treating any entry as verified editable.
