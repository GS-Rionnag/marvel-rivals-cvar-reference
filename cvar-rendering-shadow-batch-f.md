# Rendering shadow CVar batch F

This page documents the next 25 uncovered `r.Shadow.*` names in the community registry. Snapshot values are observations from an attachment with an unknown build and capture method; they are not verified Marvel Rivals defaults or recommendations. Exact-name Unreal Engine 5.9 matches are upstream context only and do not prove the game uses the same engine implementation or enables the related renderer path.

The saved scan targets Marvel Rivals Shipping build `1.1.4042190`. A direct-memory candidate means an instruction accesses the registry's recorded CVar value address. It does not recover the full branch, prove the path runs in a match, or establish that a startup `.ini` override is accepted.

## What the evidence establishes

Nine of the 25 names have at least one direct `ref_rva` candidate in the saved build scan: `SectionLevelCull`, `SkipCullingNaniteMeshes`, `SkipVSMShaderCompile`, `SpotLight.MaskBoxAsScreenRadius`, `StencilCulling`, `StencilOptimization`, `TranslucentPerObject.ProjectEnabled`, `UseDirMaskBoxCheck`, and `UseOctreeForCulling`. The other names either have only registration/object-address evidence or, for `var` rows, no `ref_rva` value address. These are static observations, not complete control-flow traces. The scan may miss indirect accesses or use sites in other binaries.

Neither a `var`/`ref` label, an upstream UE match, a captured snapshot value, nor a direct memory access proves that a startup `.ini` override is accepted, wins over later configuration, or changes a live match. This batch had no controlled override, live console query, or in-game shadow comparison. Treat the snapshot as an observation, not a preset.
