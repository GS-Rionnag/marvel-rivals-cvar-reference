# Ray tracing CVar notes: batch C

This guide records the next 25 uncovered `r.RayTracing.*` variables in the community registry. All 25 have an exact-name entry in Epic's Unreal Engine 5.9 CVar reference. That match adds upstream help/default context; it does not prove that Marvel Rivals uses the same engine implementation or enables the ray-tracing path. Snapshot values come from a separate attachment with unknown build and capture method, so they are observations, not verified game defaults or recommendations.

## What this establishes about the game

All 25 names have exact-name matches in the Unreal Engine 5.9 reference, but that is upstream context rather than proof that Marvel Rivals uses the same engine revision or has ray tracing active. The build scan found direct `ref_rva` value-access candidates for five entries: the three landscape update controls, `MaxBuiltPrimitivesPerFrame`, and `PendingBuildPriorityBoostPerFrame`. The remaining 20 are registered as `var`; their `obj_rva` address/setup matches do not prove a consumer reads a changed value. The six direct candidates do not identify a complete call path or prove a branch runs in a live match.

No live console query, controlled startup-INI override, or in-game ray-tracing comparison was performed. A syntactically valid override line and a captured snapshot value do not prove the mod loader accepts the setting, that the setting survives later config layers, or that it changes a game path. The snapshot also differs from stated help for `LandscapeGrass`; and the community and Epic descriptions disagree about the stated default for `NiagaraRibbons`.

For neighboring ray-tracing variables, see [batch A](cvar-rendering-raytracing-batch-a.md) and [batch B](cvar-rendering-raytracing-batch-b.md). The [community CVar registry](cvar-community-registry.md) separates supplied help/snapshots from exact-name UE matches; [build-specific static-analysis notes](EVIDENCE.md#build-specific-static-analysis) explains the difference between object/setup references and value-access candidates.
