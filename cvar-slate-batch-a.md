# Slate CVar batch A: UI rendering, text, and input

This guide covers the first 25 currently uncovered registered `Slate.*` CVars in registry order. These settings concern Slate/UMG rendering, widget processing, text layout, accessibility, and input behavior. Their presence in the registry does not establish that every path is used by Marvel Rivals or that an override is accepted.

Community help, the captured snapshot, and exact-name Epic UE 5.9 references are presented separately. The dump’s build and capture method are unknown. Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`; direct-memory candidates do not distinguish reads from writes or prove runtime use. `var` object references may be setup code. No live query, override test, or UI comparison was performed.

## Reading these settings

- Community help describes widget accessibility work budgets, background blur, disabled-widget appearance, text direction and shaping, retained rendering, font antialiasing, and input/navigation behavior where available.
- Snapshot/upstream differences include `Slate.EnableGlobalInvalidation` and `Slate.EnableDrawEvents`. Snapshot values are not recommendations, and Epic defaults are not confirmed Marvel Rivals defaults.
- Some names are internal testing or VR-related controls. The static registry and address scan do not prove retail exposure or safe runtime modification.

For the full candidate inventory, see the [community CVar registry](cvar-community-registry.md); build scan scope is summarized in the [build-specific static-analysis notes](EVIDENCE.md#build-specific-static-analysis).
