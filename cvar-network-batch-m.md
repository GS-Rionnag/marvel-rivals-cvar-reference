# Lower-case network CVar batch M

This guide documents 25 lower-case `net.*` variables that are not covered by earlier explanatory tables or focused prose guides. It follows batch L and uses the community registry order for selection. The community snapshot has no verified game build/capture method; Epic UE 5.9 matches are upstream context, not proof of Marvel Rivals defaults.

Build evidence comes from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. Direct-memory hits can be reads, comparisons, or writes; CVar-object hits for `var` rows may be registration/setup. No runtime path, live console value, `.ini` acceptance, or network behavior was tested.

## Limits and interpretation

- The documented descriptions cover socket recreation and receive batching, IP relay filtering, NetGUID handling, NetDriver diagnostics/encryption, shared replication serialization, channel lifecycle, and subobject replication. Names without usable help are marked unresolved.
- The two RelayMode descriptions are English renderings already marked unreviewed in the source translation catalog; retain the original help for independent review.
- Snapshot values are captured values, not recommendations. A dash in the Epic column means no exact UE 5.9 default was recorded.
- Static address references establish neither runtime execution nor that an override affects the match. Network settings may affect client/server behavior and require controlled testing before recommendation.
