# HairStrands CVar batch C: deep shadows, dumps, and system controls

This guide documents the next 25 alphabetically sorted registered `r.HairStrands.*` variables after the existing HairStrands batches A and B. It covers depth-of-field composition, deep-opacity-map hair shadows, dual scattering, groom-asset/component dumps, the hair-strands system switch, and a voxelization limit. The community registry’s `var`/`ref` kind is source metadata, not proof that a game startup override is accepted.

The table records the community snapshot as captured. Epic UE 5.9 exact-name descriptions/defaults are separate upstream references; neither the snapshot nor an upstream default is asserted as Marvel Rivals’ effective value. The community attachments do not identify their game build or capture procedure.

Build evidence is from static address-reference scanning of Marvel Rivals Shipping build `1.1.4042190`. The scan class `direct-memory-candidate` is retained as a candidate (it can indicate a read, write, or comparison); `address-taken` is separately counted. Neither class establishes an executed code path. No function trace, live CVar query, controlled config override, or in-game A/B was performed.

## What the evidence does and does not say

- DeepShadow help describes deep-opacity-map rendering, shadow filtering, resolution, sampling, density compensation, and a GPU-driven path. These are descriptions of intended controls; the supplied binary scan does not prove each option is active or how each setting affects a match.
- The four `Dump.*` controls are described as dumping groom assets, bindings, or active groom components. The dump destination, output volume, and activation timing are not specified in the community help.
- `r.HairStrands.Enable` is documented upstream as enabling/disabling strand, card, and mesh representations. It is registered as `var`; the available scan only gives object-address evidence, not direct evidence that a changed value is consumed in the game.
- A missing UE 5.9 entry is recorded as `—`; no effective Marvel Rivals default is inferred. Captured snapshot values are not recommendations.
- Static references are not proof of `.ini` acceptance. The game’s override behavior and visual result remain untested for this batch.
