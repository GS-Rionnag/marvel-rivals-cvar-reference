# Slate CVar batch C: font resources, focus, and tooltips

This batch covers the next 25 alphabetically sorted registered `Slate.*` names after the published guides and the local batch B draft. It includes font/SVG atlas limits, outline font rendering, scissor behavior, focus and gamepad controls, low-resolution RetainerWidget options, viewport behavior, UI sleep timing, cursor scale, responsiveness, and tooltip wrapping.

Snapshot values come directly from the supplied `CVarDump.txt`. Epic UE 5.9 values are exact-name upstream references and are not asserted as Marvel Rivals defaults. The supplied registry’s `var`/`ref` kind does not prove override acceptance or runtime effect.

Build evidence comes from a static address-reference scan of Marvel Rivals Shipping build `1.1.4042190`. Counts keep the scan’s `direct-memory-candidate` class separate from `address-taken`; candidates may be reads, writes, comparisons, or initialization and are not a control-flow/runtime trace.

## Evidence mismatches and limits

- `Slate.MaxFontAtlasPagesBeforeFlush` has a captured value of 8 and an Epic UE 5.9 reference default of 1.
- `Slate.RequireFocusForGamepadInput` has a captured value of `true` and an Epic UE 5.9 reference default of `false`.
- `Slate.PreventDuplicateMouseEventsForTouchForWindows7` is described for Windows 7 and older; its documented purpose should not be generalized to current Windows input behavior.
- `Slate.TargetFrameRateForResponsiveness` describes the editor’s UI responsiveness threshold. The help does not establish an effect on the shipped game client.
- Empty or placeholder help is left unresolved even when a CVar has an upstream default. Static address matches do not prove accepted startup overrides or visible UI effects.
